# Phase p_0.1.3 — Tools and sandbox

**Status:** done

## Goals

Implement built-in tools with cwd path sandbox and output truncation.

## Scope

- Tools: `read_file`, `write_file`, `edit_file`, `grep`, `glob`, `shell`
- Path containment under resolved `cwd`
- Default 64 KiB truncation on tool results
- `AllowShell` gate
- Unit tests for escape attempts and edit uniqueness

## Non-goals

- MCP tools
- Custom caller-registered tools
- OS-level sandbox / containers

## Tasks

1. Add `internal/tools` registry and JSON schemas.
2. Implement six tools per design 04.
3. Enforce path sandbox (including symlink best-effort).
4. Truncate large outputs with a visible marker.
5. Tests: `../` escape, absolute path outside cwd, edit_file not unique.

## Acceptance

- [x] Escape paths fail closed (tool error, no IO outside cwd).
- [x] `AllowShell=false` omits shell from registry.
- [x] `go test` covers sandbox and edit_file cases.
