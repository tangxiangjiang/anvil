# Phase p_0.1.4 — Runtime loop, Stream, Wait, Prompt

**Status:** done

## Goals

Wire LLM + tools into the agent run loop and deliver working `Send` / `Stream` / `Wait` / `Prompt`.

## Scope

- `internal/runtime` tool-calling loop
- `internal/prompt` system prompt
- Default `MaxSteps` (e.g. 32)
- Event emission: assistant, tool_call, tool_result, done/error
- `Prompt` one-shot (create → send → wait → close)
- Single-flight: reject concurrent Send on same Agent
- In-memory conversation for the process lifetime (no JSONL yet)

## Non-goals

- Resume / disk persistence
- Cancel API (ctx cancel on Wait/Stream is enough if documented)
- MCP / custom tools

## Tasks

1. Implement loop per design 03.
2. Connect Agent.Send to runtime; expose Stream channel and Wait.
3. Implement Prompt convenience.
4. Emit structured events; set RunResult status correctly.
5. Integration-style test with mock Completer driving one tool call then finish.

## Acceptance

- [x] Mocked run: user message → tool_call → tool_result → finished.
- [x] Stream closes after terminal event; Wait returns matching RunResult.
- [x] Prompt disposes agent (Close) after completion.
