**Status:** done

## Goals

Implement `internal/llm` with a shared `Completer` and two adapters:

1. OpenAI-compatible Chat Completions + tool calling  
2. Anthropic Messages API + tool_use / tool_result  

## Scope

- `Options.Provider`: `openai` (default) | `anthropic`
- HTTP clients with `BaseURL`, API key, model ID
- Map internal messages/tools â†?each wire format
- Error mapping to retryable / non-retryable
- `Completer` interface for tests
- Non-streaming first; SSE optional if low cost

## Non-goals

- Runtime loop wiring (p_0.1.4)
- Tool execution
- Cursor Bridge / other LLM protocols
- Required dependency on official OpenAI/Anthropic Go SDKs (stdlib `net/http` + JSON)

## Tasks

1. Add `internal/llm` + `Completer` interface.
2. Implement OpenAI-compatible adapter (`/chat/completions`, `tools` / `tool_calls`).
3. Implement Anthropic adapter (`/v1/messages`, `tools` / `tool_use` / `tool_result`).
4. Map HTTP failures (401, 429, 5xx) with Retryable flags for both.
5. Unit tests with `httptest` for both adapters (chat + one tool round-trip each).
