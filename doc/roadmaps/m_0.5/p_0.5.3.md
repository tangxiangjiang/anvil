# Phase p_0.5.3 — Eval harness

**Status:** planned

## Goals

Regression harness for agent behaviors without live network.

## Scope

- `source/eval/` or `source/internal/eval` with fixture tasks (e.g. edit file, respect sandbox deny)
- Mock Completer scripts checked in
- `go test` target or small CLI `go run ./examples/eval`

## Non-goals

- Leaderboard / LLM-as-judge online eval
- Paying API bakeoffs

## Tasks

1. Define task manifest format in this phase.
2. Implement runner + 2–3 fixtures.
3. CI-friendly `go test` entry.

## Acceptance

- [ ] `go test` (or documented command) runs fixtures offline and fails on regressions.

## Depends-on

- Milestone 0.3 tools/hooks
