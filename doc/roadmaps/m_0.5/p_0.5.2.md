# Phase p_0.5.2 — Usage aggregation

**Status:** planned

## Goals

Expose reliable usage totals for operators and CI logs.

## Scope

- Sum usage across steps into RunResult (already partial) and optional Agent.Usage()
- Persist usage on run_end (already) and read back on Get
- Document when providers omit usage

## Non-goals

- Cost currency conversion
- Per-tool token attribution

## Tasks

1. API surface for usage readback.
2. Tests with mock usage fields.
3. oneshot prints usage when present.

## Acceptance

- [ ] After a mock run with usage, totals are available on RunResult and from store metadata.
