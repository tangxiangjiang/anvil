# Phase p_0.5.2 — Usage aggregation

**Status:** done

## Goals

Expose reliable usage totals for operators and CI logs.

## Scope

- `RunResult.Usage` from provider step sums (existing) covered by tests
- Cumulative usage on `AgentInfo` / `Get` / `Agent.Usage()` from `run_end` records
- oneshot prints usage when present
- Providers may omit usage; then fields stay nil / zero

## Non-goals

- Cost currency conversion
- Per-tool token attribution

## Tasks

1. API surface for usage readback.
2. Tests with mock usage fields.
3. oneshot prints usage when present.

## Acceptance

- [x] After a mock run with usage, totals are available on RunResult and from store metadata.
