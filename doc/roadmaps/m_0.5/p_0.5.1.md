# Phase p_0.5.1 — Agent list and get

**Status:** planned

## Goals

Enumerate and inspect local agents from the JSONL store.

## Scope

- `Agent.List(ctx, opts)` / `Agent.Get(ctx, id, opts)` (names may match design 02 extensions)
- Return id, cwd, model, updated time, last status if known
- Filter by cwd

## Non-goals

- Archive/delete GC beyond optional delete file API
- Remote listing

## Tasks

1. Extend store with list directory + parse meta.
2. Public API + tests.
3. Document in README.

## Acceptance

- [ ] List returns created agents for a temp cwd.
- [ ] Get missing id → non-retryable error.

## Depends-on

- p_0.2.1 store
