# Milestone 0.1 — MVP

**Status:** done  
**Product version:** 0.1.x

## Goals

Ship a **referencable** local-only Go Agent SDK:

- `Create` / `Prompt` / `Close`
- `Send` / `Stream` / `Wait`
- LLM clients: OpenAI-compatible **and** Anthropic Messages, with tool calling
- Built-in tools: read / write / edit / grep / glob / shell with cwd sandbox
- `examples/oneshot` + unit tests with mock LLM

## Overall acceptance

1. `go test ./...` passes (mock LLM; sandbox tests).
2. With a real API key, `examples/oneshot` can read a file, apply an edit, and optionally run a command under `cwd`.
3. Public API matches [02-public-api.md](../design/02-public-api.md) for 0.1 surface (no Resume/Cancel required).

## Non-goals

- `Resume` / JSONL persistence (→ 0.2)
- `Cancel` full semantics (→ 0.2)
- MCP / custom tools / approval hooks (→ 0.3)
- Cloud runtime
