# Milestone 0.6 — Scale

**Status:** done  
**Product version:** 0.6.x

## Goals

Make Anvil usable on longer / harder local coding runs and host integrations: run progress observability, heavier offline eval, MCP beyond stdio, optional SQLite store, and a first-party CLI.

## Overall acceptance

1. Stream exposes step progress; MaxSteps exceeded is machine-detectable.
2. `go test ./eval` covers multi-file and limit-path fixtures beyond 0.5.
3. At least one non-stdio MCP transport works in tests.
4. Optional SQLite backend supports Resume / List / Get.
5. `go run ./cmd/anvil prompt …` (or built binary) can smoke a local coding run.

## Non-goals

- Multi-agent / sub-agents
- IDE plugin / deep LSP
- Cloud / remote VM / auto-PR
- Cursor Bridge adapter
- Additional LLM wire protocols beyond OpenAI-compatible and Anthropic
- Automatic JSONL → SQLite migration tool
- MCP OAuth / productized auth flows
