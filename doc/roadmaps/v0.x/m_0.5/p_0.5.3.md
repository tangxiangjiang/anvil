# Phase p_0.5.3 — Eval harness

**Status:** done

## Goals

Regression harness for agent behaviors without live network.

## Scope

- Package `github.com/anvil-dev/anvil/eval` with fixture tasks + scripted Completer
- Fixtures: unique `edit_file`, sandbox escape deny, `apply_patch` add
- CI entry: `go test ./eval`

## Task shape

```text
Name, UserMsg, Setup(dir), Script[]assistant messages, Check(dir, Result)
```

## Non-goals

- Leaderboard / LLM-as-judge online eval
- Paying API bakeoffs

## Tasks

1. Define task manifest format in this phase.
2. Implement runner + 2–3 fixtures.
3. CI-friendly `go test` entry.

## Acceptance

- [x] `go test ./eval` runs fixtures offline and fails on regressions.
