# Phase p_0.5.1 — Agent list and get

**Status:** done

## Goals

Enumerate and inspect local agents from the JSONL store.

## Scope

- Package funcs `List` / `Get` (Cursor-style static surface in Go)
- Return id, cwd, model, timestamps, last status / run id, run count
- Scoped by `ListOptions.Local.CWD`

## Non-goals

- Archive/delete GC
- Remote listing

## Tasks

1. Extend store with `ListIDs` + `Summarize`.
2. Public API + tests.
3. Document in README.

## Acceptance

- [x] List returns created agents for a temp cwd.
- [x] Get missing id → non-retryable error.

## Depends-on

- p_0.2.1 store
