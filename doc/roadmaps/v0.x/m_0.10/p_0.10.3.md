# Phase p_0.10.3 — Force, Reload, ListRuns

**Status:** done

## Goals

Operator knobs Cursor SDK local exposes for stuck runs and run inspection.

## Scope

- `Force`: if a run is active, cancel/expire it then accept the new message
- `Agent.Reload()`: re-read file-based MCP/rules/hooks without disposing
- `ListRuns(agentID)` / get run over store `run_start`/`run_end`
- Tests for force and listRuns on temp store

## Non-goals

- Cloud `409 agent_busy` semantics
- Full Cursor run object field parity

## Tasks

1. Implement Force on Send path.
2. Implement Reload.
3. Persist enough run metadata for ListRuns; public API + tests.
4. Update design 02 / 06 / 10.

## Acceptance

- [x] Second Send without Force fails while busy; with Force succeeds after cancelling the prior run.
- [x] ListRuns returns at least completed runs for an agent with multiple Send cycles.

## Depends-on

- 0.2 Cancel; 0.5 List/Get; 0.6 store backends
