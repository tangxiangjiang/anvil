# Phase p_0.10.1 — settingSources and config layers

**Status:** done

## Goals

Load project/user MCP and rule layers the way Cursor SDK local does via `local.settingSources`.

## Scope

- `LocalOptions.SettingSources` (e.g. `project`, `user`; empty = inline-only, current behavior)
- Project: `.cursor/mcp.json` under cwd; continue supporting Anvil rules paths
- User: `~/.cursor/mcp.json` (and documented Anvil user rules path if any)
- Precedence vs inline `MCPServers`; Resume re-passes inline MCP; file sources re-read when enabled
- Design note in 02 / 09 / 10

## Non-goals

- Cursor plugins marketplace / dashboard servers
- MCP OAuth login UI

## Tasks

1. Define public `SettingSources` type and precedence.
2. Parse `.cursor/mcp.json` into `MCPServerConfig`.
3. Wire Create/Resume; tests with fixture trees.
4. Document in README.

## Acceptance

- [x] With `SettingSources` including `project`, an agent sees tools from fixture `.cursor/mcp.json` without inline `MCPServers`.
- [x] Without `SettingSources`, file MCP is not loaded (inline-only).

## Depends-on

- 0.6 MCP HTTP/SSE + stdio
