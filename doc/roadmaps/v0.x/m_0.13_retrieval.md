# Milestone 0.13 — Retrieval quality

**Status:** done  
**Product version:** 0.13.x

## Goals

Add local **codebase index** + **`semantic_search`** (lexical required, embeddings optional via gateway) so agents beat grep-only on medium repos.

## Overall acceptance

1. `semantic_search` returns relevant chunks on a fixture repo without embeddings.
2. With embed endpoint configured, hybrid path runs and persists vectors under `.anvil/index/`.
3. Path sandbox + secret denylist respected while indexing.
4. MCP alternative documented; not required for acceptance.

## Non-goals

- Cursor Composer recall parity
- Cross-repo global index
- Web search

## Depends-on

- 0.10 tools registry; prefer 0.12 embed endpoint availability (optional)
