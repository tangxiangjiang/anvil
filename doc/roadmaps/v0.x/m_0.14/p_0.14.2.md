# Phase p_0.14.2 — Opt-in command hooks

**Status:** done

## Goals

Allow `command` + `timeoutMs` on selected hook entries when explicitly enabled.

## Scope

- `Options.AllowHookCommands` (default false)
- Run script relative to cwd; exit non-zero → deny
- Timeout + output truncation + redact

## Non-goals

- Network services as hooks
- Windows service account complexity beyond smoke

## Tasks

1. Executor with timeout.
2. Security tests: disabled by default.
3. Fixture script allow/deny.

## Acceptance

- [x] With AllowHookCommands false, `command` field is ignored or create warns and does not execute.
- [x] When enabled, exit 1 denies shell/MCP as configured.

## Depends-on

- p_0.14.1
