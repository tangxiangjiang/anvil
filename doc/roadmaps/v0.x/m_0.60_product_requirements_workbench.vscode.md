# Milestone 0.60 — Product requirements workbench

**Status:** planned

Make VS Code the only interactive entry point for product requirements and AI-assisted delivery.
The service remains authoritative; Web begins its transition to read-only audit. Design:
[60](../../design/v0.x/60-product-requirements-workbench.vscode.md).

## Goals

1. Add a revisioned Requirement artifact and bind service state to optional Git-backed documents.
2. Add VS Code Product navigation, requirement editing/review, and artifact-aware AI Chat.
3. Remove Web Chat and requirement mutations after migration/parity gates pass.

## Ordering

The durable requirement contract lands before UI. Cutover occurs only after import, reconnect,
authorization, accessibility, and audit tests prove the VS Code path.

## Overall acceptance

- A requirement is created, revised, reviewed, and approved entirely in VS Code.
- AI Chat references exact artifact revisions and cannot mutate without a reviewed diff.
- Reload/reconnect preserves artifact, Session, selection, and audit state.
- Web can inspect/export requirements but has no Chat or requirement mutation.
- Requirement approval starts no planning or execution.

## Non-goals

- Design/roadmap planning (0.61) or implementation (0.62).
- Making extension storage authoritative.
- Removing historical Web audit records.
