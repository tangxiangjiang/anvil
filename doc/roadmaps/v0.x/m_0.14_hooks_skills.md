# Milestone 0.14 — Hooks & skills deepen

**Status:** done  
**Product version:** 0.14.x

## Goals

Expand file hooks beyond shell/write/edit gates and add **skills** discovery/injection so hosts can encode workflow playbooks without Cursor plugins.

## Overall acceptance

1. Hooks can deny an MCP tool call via `beforeMCP`.
2. Skills directories are discovered; model can `list_skills` / `read_skill`.
3. `always` skills appear in system context with size caps.
4. Command hooks default off; when enabled, non-zero exit denies.
5. Not claiming full Cursor hooks/skills UI parity.

## Non-goals

- Plugins marketplace / team MDM
- Spawning sub-agents from skills
- Interactive approval UI

## Depends-on

- 0.10 minimal hooks + settingSources
- MCP registry for beforeMCP tests
