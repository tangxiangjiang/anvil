# Milestone 0.7 — Streaming & errors (design 07)

**Status:** done  
**Product version:** 0.7.x  
**Design:** [07-streaming-and-errors.md](../../design/v0.x/07-streaming-and-errors.md)

## Goals

Harden the event/error contract from design 07 so hosts (CLI, CI, long UE-style runs) get reliable, machine-readable outcomes—not only the MVP stream types.

Much of 07 already shipped in 0.1–0.6 (`assistant`/`tool_*`/`done`/`error`/`progress`, `RunResult`, `IsMaxStepsExceeded`). This milestone closes the remaining gaps called out in the chapter.

## Overall acceptance

1. Stream `error` / `RunResult` expose a stable code field (or documented equivalent) for limit / cancel / provider classes.
2. Outer context deadline is not silently labeled the same as `MaxWallTime` without distinction.
3. CLI (or small helper) can log agentID/runID without printing secrets; CI exit codes remain 1 vs 2.

## Non-goals

- Changing the core Create/Send/Wait shape
- Full OpenTelemetry product
- Cursor event wire compatibility
