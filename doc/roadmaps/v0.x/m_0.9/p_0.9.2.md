# Phase p_0.9.2 — Parallel tool execution

**Status:** done

## Goals

Design 03 noted sequential tools in 0.1 with parallel optional later; expose opt-in parallel execution for a single assistant turn’s tool_calls (design 09 compatibility: additive).

## Scope

- `Options.ParallelTools` or equivalent (default off = sequential)
- Same-turn tool_calls run concurrently with bounded concurrency
- Emit tool_call/tool_result events in a documented order (start order or completion order—pick one and test)
- Mutating tools: either force sequential for mutating set or document race risk

## Non-goals

- Speculative tools / planner multi-agent

## Tasks

1. Runtime loop change behind flag.
2. Tests with fake slow tools.
3. Design 03/09 notes.

## Acceptance

- [x] Default remains sequential (existing tests green).
- [x] With opt-in, two read-only tools in one step overlap in time (test with sleep fakes).
