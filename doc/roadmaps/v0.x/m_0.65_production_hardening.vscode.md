# Milestone 0.65 — Production hardening and release confidence

**Status:** planned

Prove the product across platforms, long runs, failures, scale, diagnostics, migrations, and
release/rollback boundaries. Design:
[65](../../design/v0.x/65-production-hardening.vscode.md).

## Goals

1. Build a required platform/compatibility matrix with fault, soak, and scale gates.
2. Add privacy-preserving diagnostics and opt-in telemetry.
3. Automate reproducible release qualification, migration, provenance, and rollback checks.

## Overall acceptance

- Required Windows/macOS/Linux matrices pass from clean environments.
- Fault tests prove each durable mutation is completed or recoverable/blocked.
- Soak/scale stay within versioned resource and latency budgets.
- Support/telemetry exports contain no forbidden content.
- Upgrade/rollback and artifact provenance are machine-gated.

## Non-goals

- Content telemetry, zero-defect claims, or supporting every historical platform/tool version.

## Depends-on

- 0.60–0.64 so their high-risk paths enter the common qualification gates.
