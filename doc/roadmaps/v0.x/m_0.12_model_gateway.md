# Milestone 0.12 — Model gateway

**Status:** done  
**Product version:** 0.12.x

## Goals

Ship a **model gateway** (catalog + auth + OpenAI-compatible proxy) and a thin Anvil catalog client so hosts stop depending on Cursor `models.list`.

## Overall acceptance

1. Client with gateway token can `GET /v1/models` and complete a streamed chat via gateway.
2. Upstream keys never appear in client requests or gateway error bodies.
3. Anvil agent against gateway `BaseURL` passes an existing smoke/oneshot path.
4. Design non-goals (Cursor Router clone, training) remain explicit.

## Non-goals

- Cursor auto / account router
- cloud-agent task Gateway replacement
- Anthropic-only deployments without OpenAI-compat (optional passthrough only)
