# Milestone 0.61 — Remote Git, pull requests, and CI

**Status:** planned

Publish exact reviewed commits, manage pull requests explicitly, observe CI durably, and turn
failed checks into bounded approved repair attempts. Design:
[61](../../design/v0.x/61-remote-git-pr-ci.vscode.md).

## Goals

1. Establish provider, repository, credential, ref, and publication policy boundaries.
2. Add explicit, idempotent pull-request creation/update and reviewable content.
3. Observe checks and create bounded fix attempts through the 0.60 path.

## Overall acceptance

- Tokens never enter prompts, stores, Worktrees, Git config, or command output.
- Only an exact reviewed commit can be pushed to a policy-approved remote/ref.
- PR writes are explicit, revision-bound, idempotent, and previewed.
- CI survives reconnect/restart and starts no repair attempt without approval.
- Drift, protection, missing scopes, outages, and rate limits fail closed.

## Non-goals

- Force push, automatic merge/approval, branch-protection bypass, or every provider.
- Remote Worker execution.
