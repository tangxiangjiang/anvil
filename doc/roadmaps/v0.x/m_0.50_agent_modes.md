# Milestone 0.50 — Agent modes

**Status:** done
**Product version:** 0.50.0

Chapter 47's layered prompts and roles give every agent an explicit job and an unremovable
safety layer. This milestone adds the mode ladder — Single, Multi, Complex — as SDK interfaces:
`Options.Mode`, the `delegate` tool with its structured brief, and a Complex run expressed as a
workflow with three new step fields. The host and worker containers supply model and effort from
their configuration; the SDK reads no configuration files. The design is chapter
[50](../../design/v0.x/50-agent-modes.md).

## Goals

1. **Multi.** `delegate(brief)`: a validated goal / plan / files / acceptance hand-off, a write
   allowlist enforced by the permission engine, and an acceptance report the parent can read
   line by line.
2. **Complex.** Decision → Analyze → Worker as a workflow the SDK builds, with `role`,
   `effort` and `result_schema` on a step, two validated schemas, and item-level dependencies
   in a fan-out.
3. **Anvil's own capabilities, under every mode.** The 0.47 invariants suite runs per mode
   and stays at 100%; a child's checkpoint is keyed under the tree's root run so one restore
   undoes a Complex run.

## Overall acceptance

1. A `delegate` brief missing `files` or `acceptance` is refused before any agent starts; a
   worker's edit outside `files` is refused by a rule, not by the prompt; the parent's result
   carries a `[met]`/`[not met]`/`[unreported]` line per acceptance item and a `changed:` line
   from the checkpoint record.
2. A Complex `Send` runs three stages as a workflow; an Analyze result that fails the
   `roadmap` schema fails that step and starts no Worker; roadmap items with `depends_on`
   run in dependency order.
3. `./scripts/eval.sh --suite invariants --mode single,multi,complex` is 100% in all three;
   `RestoreCheckpoint` on a Complex run's root restores every Worker's edits.
4. `./scripts/eval.sh` not worse than the 0.49 baseline on every gated field.
5. `cd source && go build ./... && go vet ./... && go test -count=1 ./...` green (run from
   Git Bash) at the end of every phase.

## Non-goals

- Host protocol, worker config, CLI flags, VS Code settings or cards for modes or briefs. The
  SDK emits the events and takes the options; the containers adapt.
- A model-driven mode router; changing the mode within a session; a reviewer stage; a re-plan
  loop after a failed Worker.
- Persisting the mode in the transcript.
- A plan-file hand-off between parent and child.
