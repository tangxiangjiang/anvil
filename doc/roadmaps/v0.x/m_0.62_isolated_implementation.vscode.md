# Milestone 0.62 — Isolated implementation

**Status:** planned

Execute one approved 0.61 work item through a host-owned Worktree transaction and enforced local
sandbox, with all operations controlled from VS Code. Design:
[62](../../design/v0.x/62-isolated-implementation.vscode.md).

## Goals

1. Atomically validate, prepare, route, and start one durable isolated implementation attempt.
2. Enforce runtime, mount, resource, network, secret, lifecycle, and cleanup policy.
3. Provide VS Code preflight, live evidence, cancellation, retry, recovery, and Worktree handoff.

## Overall acceptance

- Duplicate/stale/blocked starts create no run; accepted starts share one identity tuple.
- Sandbox escape, host reads, secret leaks, unsupported isolation, and resource abuse fail closed.
- Cancel/restart/retry have durable outcomes and preserve previous evidence.
- Primary checkout remains unchanged until explicit later integration.
- Web can audit execution but cannot start, stop, retry, or configure it.

## Non-goals

- Remote Worker scheduling (0.66).
- Verification, review, PR/CI, merge, or release (0.63–0.65).
