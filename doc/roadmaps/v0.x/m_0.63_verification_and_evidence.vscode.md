# Milestone 0.63 — Verification and evidence

**Status:** planned

Verify an implementation against approved acceptance with durable local, browser, desktop, and
manual evidence controlled from VS Code. Design:
[63](../../design/v0.x/63-verification-and-evidence.vscode.md).

## Goals

1. Add revision-bound verification campaigns and acceptance-to-evidence coverage.
2. Add a fail-closed browser/desktop capability ladder with protected secrets and explicit writes.
3. Add bounded repair handoff and remove Web test/browser/acceptance mutations.

## Overall acceptance

- Every required criterion has current attributable evidence or an explicit non-pass state.
- Browser/desktop actions respect capability, origin, target, secret, and approval boundaries.
- Failed verification cannot silently rerun or start unbounded repair.
- Live and restored evidence agree; passive viewing performs no mutation.
- Web has read-only campaign and evidence audit.

## Non-goals

- Autonomous review, Git/PR/CI delivery, merge, or release (0.64–0.65).
- General remote desktop, CAPTCHA bypass, elevation, or remote browser fleets.
