# p_0.46.68 — Per-turn reasoning effort

**Status:** done

## Goal

Let the user choose Low, Medium, or High reasoning effort beside the model
selector without locking the composer while an answer is running.

## Scope

- Default new VS Code conversations to Medium effort.
- Snapshot effort with Model and Mode for Send, Enqueue, and Steer turns.
- Apply a queued selection only when that turn starts.
- Carry effort through the editor-host and SDK request path.
- Map effort to OpenAI-compatible `reasoning_effort` and Anthropic thinking
  budgets while preserving signed Anthropic thinking blocks across tool loops.

## Acceptance

- [x] The composer exposes Low, Medium, and High beside Model.
- [x] Effort remains selectable during a running response.
- [x] Queued turns retain the effort selected when they were submitted.
- [x] Provider, runtime, host, queue, and UI tests pass.
- [x] The 0.46.64 VSIX passes packaged smoke and installs locally.
