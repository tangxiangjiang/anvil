# p_0.46.82 — Fold restored plans until a new plan appears

**Status:** done

## Goal

Start the live task Plan folded, while still drawing attention to genuinely new
Plan content by expanding it automatically.

## Scope

- Render the Plan in its collapsed shape on webview startup.
- Keep plans reconstructed during transcript replay collapsed.
- Expand when a distinct live Plan revision first appears.
- Keep status-only updates from reopening a manually folded Plan.
- Reset to collapsed before switching or replaying another conversation.

## Non-goals

- Changing plan-mode approval cards or Plan documents.
- Persisting the manual fold state across windows.
- Changing the retained Plan history limit.

## Tasks

- [x] Centralize collapsed-state DOM and accessibility updates.
- [x] Distinguish new live Plan revisions from replay and status updates.
- [x] Add regression coverage and package the synchronized patch release.

## Acceptance

- [x] A newly opened or restored chat starts with Plan folded.
- [x] Transcript replay does not expand Plan.
- [x] A new live Plan expands automatically.
- [x] Status updates do not override manual collapse.
- [x] Extension tests and packaged smoke pass.
