# p_0.46.40 — Right-aligned green user bubbles

**Status:** done

**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §43

## Goals

Make the user's side of the conversation visually distinct from the agent's reply.

## Scope

- Render user text as a green, right-aligned chat bubble.
- Right-align the text inside the bubble.
- Cap the bubble at two thirds of the transcript's content width.
- Keep short prompts content-sized and preserve wrapping for long prompts.

## Acceptance

- [x] User bubbles are visibly green in editor themes.
- [x] User bubbles and their text align right.
- [x] A bubble is content-sized up to a `66.666%` maximum width.
- [x] Compile, lint, 532 unit tests, package and packaged smoke pass.
