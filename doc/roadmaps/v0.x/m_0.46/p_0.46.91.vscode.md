# p_0.46.91 — Single tab per session

**Status:** done

## Goal

Reveal an existing chat tab whenever its Session Manager row is opened again.

## Scope

- Keep the tab's bound session id stable while a host session is restored.
- Match both bound and live agent identities when looking for an open tab.
- Reserve a `/resume` destination before asynchronous host work begins.
- Cover repeated opens and restoration races with regression tests.

## Acceptance

- [x] Clicking an already open session activates its existing tab.
- [x] Repeated clicks during session restoration do not create another tab.
- [x] A failed `/resume` restores the tab's previous identity.
- [x] Extension tests and packaged smoke pass.
