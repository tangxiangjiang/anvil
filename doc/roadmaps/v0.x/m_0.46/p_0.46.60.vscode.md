# p_0.46.60 — Resilient empty-response recovery

**Status:** done

## Goal

Reduce premature task interruption when a model gateway intermittently returns
successful responses containing neither text nor tool calls.

## Scope

- Expand bounded recovery from three to five attempts.
- Alternate streaming and complete-response transports during recovery.
- Render a root terminal failure once rather than once per event envelope.

## Acceptance

- [x] Empty recovery alternates transports and remains bounded.
- [x] A persistent empty provider response ends after five attempts.
- [x] The root transcript shows the terminal error exactly once.
- [x] Runtime, extension, packaged smoke, and local Cursor installation pass.
