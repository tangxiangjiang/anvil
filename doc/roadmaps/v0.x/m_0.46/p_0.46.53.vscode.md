# p_0.46.53 — Review-safe auto-scroll

**Status:** done

## Goal

Make following live agent output reliable without taking the reader away from
content they are reviewing.

## Scope

- Add an always-available auto-scroll toggle beside the return-to-latest action.
- When enabled, keep the transcript at its newest content through synchronous
  and asynchronous layout changes.
- When disabled, follow only while already at the bottom; preserve an upstream
  review position as new output arrives.
- Persist the preference in the webview's restored state.

## Acceptance

- [x] Auto-scroll defaults on and immediately follows new output.
- [x] Turning it off while scrolled up preserves the review position.
- [x] Turning it on jumps to the latest content and resumes following.
- [x] The pressed state, accessible label and tooltip describe the behavior.
- [x] Extension tests, packaged smoke and local VSIX install pass.
