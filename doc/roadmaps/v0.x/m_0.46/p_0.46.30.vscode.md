# p_0.46.30 — One token line with a travelling highlight

**Status:** done (2026-10-22)
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §33

## Goals

Remove the duplicate finished token line, format large counts with automatic K/M units, and
give live input/output counts plus changing forge words a travelling per-character highlight.

## Scope

The meter formatter, chat renderer/style, focused unit tests and documentation.

## Non-goals

- Animating or estimating cache while a response is in flight.
- Changing usage accounting or the editor-host protocol.

## Tasks

1. Format counts below one thousand as integers, thousands as K, and millions as M.
2. End each run with one line shaped as
   `8 steps · 829k tokens (823k in / 5.3k out) · 87% cache`.
3. Hide the live meter after terminal usage is folded into that summary.
4. Sweep a highlight across rolling input/output characters, enlarging and brightening each
   character at the highlight and restoring it behind the sweep.
5. Apply the same transition to changing forge/progress words and make that word larger and
   brighter than its metadata.
6. Compile, lint, test, package and smoke the VSIX.

## Acceptance

- [x] Finished runs show one usage line, not a summary plus a meter.
- [x] Counts select integer/K/M units from their magnitude.
- [x] Cache is a terminal percentage and does not move during a response.
- [x] Live input/output and changing forge words use the travelling character highlight.
- [x] Reduced motion changes text immediately without the travelling effect.
- [x] Verification passes.
