# p_0.46.76 — One focus frame around Plan and composer

**Status:** done

## Goal

Make the joined Plan and composer read as one focused control instead of a
grey Plan stacked above a blue composer.

## Scope

- Extend the composer's focus border around the visible Plan.
- Remove the composer's extra inner focus ring while Plan is attached.
- Preserve the standalone composer focus treatment when no Plan is visible.

## Non-goals

- Layout, history, or collapse behavior changes.
- Host or protocol changes.

- [x] Add joined focus-frame styling.

- [x] Package, smoke-test, and install the synchronized patch release.

## Acceptance
