# p_0.46.41 — A live pulse for background work

**Status:** done
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §44

## Goals

Make active background work visibly alive without flashing an entire row or claiming that a
finished task is still running.

## Scope

- Add a three-dot blue working pulse to background spawn cards.
- Use the same pulse for running rows in the Tasks panel.
- Route task lifecycle notifications back to the originating spawn card.
- Stop the animation and show the terminal task status.
- Respect reduced-motion preferences.

## Acceptance

- [x] A running background spawn has a visible, continuously moving indicator.
- [x] The Tasks panel uses the same indicator on running rows.
- [x] Finished, failed and cancelled task notifications stop the card animation.
- [x] Reduced motion shows a static indicator.
- [x] Compile, lint, 534 unit tests, package and packaged smoke pass.
