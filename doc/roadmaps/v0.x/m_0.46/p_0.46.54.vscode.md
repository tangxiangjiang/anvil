# p_0.46.54 — Queued and priority chat sends

**Status:** done

## Goal

Keep the composer useful while an agent turn is running: a new message can wait
its turn or explicitly interrupt and run next.

## Scope

- Keep text, mentions, quotes and image attachment controls available during a
  running turn.
- Add a compact Enqueue action that stores complete prompt payloads in FIFO
  order and sends the next one only after the active turn reaches a terminal
  state.
- Add an explicit Send now action that interrupts the active turn and starts
  that prompt ahead of queued work.
- Keep Stop available as a separate action and report queue state in the
  composer.
- Start priority work only after the interrupted run emits its terminal
  notification, so prompt dispatch never races session cleanup.

## Acceptance

- [x] Enter or Enqueue during a run queues the complete prompt without losing
  mentions, images or quotes.
- [x] Queued prompts run one at a time, in order, after terminal notifications.
- [x] Send now cancels the active run and starts the selected prompt before the
  existing queue.
- [x] The composer remains editable during a run and Stop remains available.
- [x] Resetting or closing a conversation clears its pending queue.
- [x] Extension tests, packaged smoke and local VSIX install checks pass.
