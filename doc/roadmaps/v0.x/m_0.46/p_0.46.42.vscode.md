# p_0.46.42 — A compact two-storey composer

**Status:** done
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §45

## Goals

Replace the nested input-box-and-button-strip look with one compact composer surface while
retaining every existing action.

## Scope

- Make the prompt a borderless top storey inside the composer card.
- Put reference, image, rules, permissions and focus actions in a compact icon rail.
- Keep permission mode and send/stop on the right.
- Preserve chips, slash commands, warnings, keyboard labels and dynamic height measurement.
- Use VS Code theme colours and focus states.

## Acceptance

- [x] The composer is one rounded surface with a quiet divider above its action rail.
- [x] All existing actions remain available and labelled for assistive technology.
- [x] The prompt starts shorter and still grows with content.
- [x] Send still turns into Stop during a run.
- [x] Compile, lint, 536 unit tests, package and packaged smoke pass.
