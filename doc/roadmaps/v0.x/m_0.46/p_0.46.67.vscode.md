# p_0.46.67 — Forced finish-protocol recovery

**Status:** done

## Goal

Recover when a tool-capable model repeatedly returns final prose but ignores
the editor's explicit `finish_task` terminal protocol.

## Scope

- Keep ordinary assistant text non-terminal.
- After bounded normal corrections, issue one non-streaming recovery request
  that advertises only `finish_task`.
- Accept only a valid standalone `finish_task` call from that request.
- Preserve the explicit protocol error if the model still does not comply.
