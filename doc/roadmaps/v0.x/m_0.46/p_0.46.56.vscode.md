# p_0.46.56 — Two-pane model settings workflow

**Status:** done

## Goal

Make model curation feel like part of configuration rather than a one-way
manager document.

## Scope

- Add an explicit return to native Anvil Settings.
- Use a default-model dropdown rather than a text field in the manager.
- Present available and gateway models as adjacent list boxes.
- Add models manually from the available pane and transfer fetched models from
  the gateway pane.
- Keep the existing settings storage and gateway protocol.

## Non-goals

- VS Code does not support embedding custom controls in its native Settings
  editor; the two-pane control remains an extension webview.
- No changes to gateway routing or model metadata.

## Acceptance

- [x] The manager returns to `@ext:anvil-dev.anvil-vscode` Settings in one click.
- [x] The default model is selected from a dropdown.
- [x] Manual add, remove, fetch, and transfer are available without leaving the page.
- [x] Extension tests, packaged smoke, and local install pass.
