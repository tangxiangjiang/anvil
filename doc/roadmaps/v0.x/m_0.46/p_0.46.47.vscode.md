# p_0.46.47 — Bounded class and code previews

**Status:** done
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §50

## Goals

Make dense class diagrams useful as topology previews and keep long code blocks from consuming the
whole conversation.

## Scope

- Render at most three attributes and three methods per class in the inline preview.
- Mark omitted class members with an ellipsis and retain the full source for View.
- Normalize Mermaid relationship lines and marker shapes to the active theme.
- Cap inline diagram and code-block height.
- Keep scrollbars transparent until hover or keyboard focus.

## Acceptance

- [x] Dense class boxes remain compact enough to show their relationships.
- [x] View renders the complete, untruncated class diagram.
- [x] Relationship arrows do not retain black Mermaid defaults in a dark theme.
- [x] Long code and diagram blocks scroll internally within a bounded height.
- [x] Scrollbar thumbs appear only while the block is hovered or focused.
- [x] Compile, lint, 631 tests, package and packaged smoke pass.
