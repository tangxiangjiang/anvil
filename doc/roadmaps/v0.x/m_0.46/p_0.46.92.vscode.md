# p_0.46.92 — Secondary Side Bar chat

**Status:** done

## Goal

Place a fully interactive Anvil conversation beside VS Code Chat and Claude Code
in the Secondary Side Bar.

## Scope

- Contribute a top-level Anvil container and webview to the Secondary Side Bar.
- Reuse the existing chat document, session protocol, composer, approvals, and replay.
- Keep explicit source-selection attachments working when the side bar owns focus.
- Keep editor chat tabs supported and prevent one stored Session from opening twice.
- Route Session Manager activation to the side-bar chat when that surface is available.

## Acceptance

- [x] Anvil appears as a peer of Chat and Claude Code in the Secondary Side Bar.
- [x] The side-bar view can start, resume, stream, stop, and approve a conversation.
- [x] Opening the Session already shown there reveals it instead of creating an editor tab.
- [x] Hiding and showing the view preserves the conversation.
- [x] Existing editor-tab restoration remains compatible.
- [x] Extension tests and packaged smoke pass.
