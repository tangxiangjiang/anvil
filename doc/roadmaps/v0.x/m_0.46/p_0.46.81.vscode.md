# p_0.46.81 — One titled tab per session

**Status:** done

## Goal

Make Session Manager navigation behave like a document list: each stored
session opens in exactly one chat tab, and that tab is named with the session's
human-readable title.

## Scope

- Use the stored session title for chat tab labels.
- Refresh open tab labels when a title is derived or renamed.
- Reveal an existing tab whenever its session is opened again.
- Remove the explicit duplicate-session-tab action.
- Deduplicate restored tabs and in-chat resume paths.

## Non-goals

- Changing how the host derives a session title.
- Preventing a fork from opening its distinct new session.
- Replacing VS Code's native Tree View with a custom sidebar webview.

## Tasks

- [x] Cache listed session titles and propagate title changes to open tabs.
- [x] Make all session-opening paths reveal an existing tab.
- [x] Remove the command that deliberately opened duplicate session tabs.
- [x] Add regression coverage and package the synchronized patch release.

## Acceptance

- [x] Session rows and their chat tabs show the same stored title.
- [x] Clicking an already-open session reveals its existing tab.
- [x] Restoring duplicate tabs keeps only one tab for the session.
- [x] Renaming a session updates its open tab.
- [x] Extension tests and packaged smoke pass.
