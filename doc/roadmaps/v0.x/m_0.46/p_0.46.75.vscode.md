# p_0.46.75 — Plan and composer joined by an edge handle

**Status:** done

## Goal

Make the live Plan feel attached to the composer and put its reversible
collapse action on the Plan frame instead of in the title row.

## Scope

- Join the visible Plan and composer with one continuous bordered surface.
- Keep Plan title and saved-plan count as labels rather than a full-width
  button.
- Place a flat, keyboard-accessible collapse handle on the shared edge.
- Rotate the handle to communicate collapse and expansion.

## Non-goals

- A floating window or separate plan editor.
- Changes to plan history, plan mode, or host protocol.

- [x] Restructure the Plan header and edge control.

- [x] No `×` appears in the live Plan.
