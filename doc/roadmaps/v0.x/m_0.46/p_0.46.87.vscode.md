# p_0.46.87 — One model setup surface

**Status:** done

## Goal

Replace duplicated native model settings with one task-oriented setup page and
make manual model entry predictable.

## Scope

- Keep Base URL, API Key, Provider, Default Effort, and Model Mode together.
- Show Model ID only for Single mode and Model Manager only for Gateway mode.
- Migrate model connection and gateway-list state out of native Settings UI.
- Make `+ Add` reveal and focus one stable manual-entry row with an explicit
  close action.

## Non-goals

- Changing provider protocols or API-key storage.
- Changing model discovery semantics.
- Moving subagent profiles out of Model Manager.

## Tasks

- [x] Consolidate model setup and API-key entry.
- [x] Migrate hidden model state without losing existing workspace values.
- [x] Refine Model Manager manual-add behavior.
- [x] Test, package, smoke-test, and install the synchronized patch release.

## Acceptance

- [x] Native Settings no longer shows duplicate model connection/list fields.
- [x] Single and Gateway modes expose only their relevant controls.
- [x] `+ Add` never toggles an existing input closed; `×` closes it explicitly.
- [x] Existing connection, catalogue, allow-list, default, and effort survive.
- [x] Extension tests and packaged smoke pass.
