# p_0.46.80 — Persist each conversation's composer model

**Status:** done

## Goal

Restore the model and reasoning effort selected in a conversation when its chat
tab is reopened, instead of silently returning the composer to workspace
defaults.

## Scope

- Store composer model and effort selections in VS Code workspace state.
- Key selections by conversation agent id so tabs do not overwrite each other.
- Restore only curated models; fall back safely when a saved model was removed.
- Remember choices made before the first prompt once the conversation gets its
  agent id.

## Non-goals

- Changing the workspace's configured default model.
- Writing UI preferences into transcript JSONL.
- Applying one conversation's selection to every new conversation.

- [x] Add bounded, validated workspace-state reads and writes.

- [x] Reopening a conversation restores its selected effort.
