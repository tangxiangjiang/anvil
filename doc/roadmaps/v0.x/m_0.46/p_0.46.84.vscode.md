# p_0.46.84 — Make Session Manager a collapsible function group

**Status:** done

## Goal

Make the whole Session Manager—including date buckets and session rows—a
collapsible section inside the Anvil sidebar, ready for future sibling function
groups.

## Scope

- Add a stable `SESSION MANAGER` root node to the native tree.
- Move New session from the outer toolbar into the function group.
- Place loading, errors, date buckets, and sessions beneath that root.
- Use the root's native chevron to fold or expand the complete feature.
- Remove the incorrectly interpreted Expand All date-groups title action.
- Keep a top-level node shape that future Anvil function groups can share.

## Non-goals

- Adding placeholder future groups.
- Replacing the native Tree View with a webview.
- Changing session sorting, grouping, or opening behavior.

## Tasks

- [x] Introduce a provider-local function-group node.
- [x] Move all Session Manager content beneath it.
- [x] Put New session inside the collapsible group.
- [x] Remove the superseded title-bar command.
- [x] Add regression coverage and package the synchronized patch release.

## Acceptance

- [x] Clicking `SESSION MANAGER` folds every session and date bucket.
- [x] The New session action folds with the group.
- [x] Clicking it again restores the complete Session Manager.
- [x] Loading and error rows remain inside the group.
- [x] No extra placeholder group is displayed.
- [x] Extension tests and packaged smoke pass.
