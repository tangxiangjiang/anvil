# p_0.46.52 — Explicit finish-task protocol

**Status:** done

## Goal

End editor-agent turns from an explicit protocol signal rather than guessing
whether natural-language assistant text sounds final.

## Scope

- Add a reserved `finish_task` control tool whose summary becomes the final
  assistant response.
- Require that signal for editor-host sessions while preserving SDK callers'
  existing default behavior.
- Treat ordinary text without another tool call as non-terminal and give the
  model bounded corrective opportunities.
- Validate that `finish_task` is called alone with a non-empty summary and only
  after background work has been joined and integrated.

## Acceptance

- [x] Ordinary text such as “我继续完成…先核对…再补齐…” cannot finish an
  editor run.
- [x] `finish_task` called alone with a summary produces the terminal answer.
- [x] Mixed, malformed or premature finish calls are corrected without entering
  durable history.
- [x] Repeated missing finish signals end as an explicit protocol error, never
  a green Summary.
- [x] Runtime tests, extension tests, packaged smoke and local VSIX install pass.
