# p_0.46.59 — Context-accurate live token share

**Status:** done

## Goal

Prevent cumulative provider usage from being presented as the current context
window size during a live response.

## Scope

- Use the editor host's context estimate for the live `last … of …` share.
- Keep provider usage only as an older-host fallback.
- Cover multi-round usage larger than the configured context window.

## Acceptance

- [x] A 2M cumulative provider total with a 100k host estimate displays 100k.
- [x] Input/output token totals retain their provider-reported values.
