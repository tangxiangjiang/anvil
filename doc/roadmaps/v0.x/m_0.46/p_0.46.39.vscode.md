# p_0.46.39 — List the files changed by each turn

**Status:** done
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §42

## Goals

Put the files the agent changed in the turn directly after that turn's visible Summary.

## Scope

- Carry the run id with the extension's changed-files message.
- Associate a completed Summary with its run.
- Insert the existing reviewable changed-file list immediately after that Summary.
- Preserve the ordinary fallback position for runs without a prose Summary.

## Acceptance

- [x] A successful turn that changed files shows their paths after Summary.
- [x] Each path retains its added, changed or deleted state and opens its diff.
- [x] Concurrent or replayed run boundaries cannot attach a list to another turn.
- [x] Compile, lint, 531 unit tests, package and packaged smoke pass.
