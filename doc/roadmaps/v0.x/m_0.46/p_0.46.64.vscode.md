# p_0.46.64 — Lifecycle-aware background polling

**Status:** done

## Goal

Keep a foreground agent alive while it legitimately waits for a running
background task, without weakening loop protection after that task ends.

## Scope

- Treat a matching `task_output` result whose lifecycle state is `running` as
  an explicit wait state rather than a stalled tool result.
- Reset generic repeat and cycle streaks when that wait state is observed.
- Keep ordinary warn/stop behavior for terminal, malformed, mismatched, and
  error results.

## Acceptance

- [x] Repeated polling of a matching running task does not stop the agent.
- [x] Repeated terminal or invalid task results still trigger loop protection.
- [x] Runtime and extension tests pass.
- [x] The 0.46.60 VSIX passes packaged smoke and installs locally.
