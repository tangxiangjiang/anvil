# p_0.46.49 — Agent collaboration modes and map

**Status:** done

## Goal

Make single-agent and delegated work explicit, and make a conversation's agent tree inspectable.

## Scope

- Add a session-scoped Single/Multi selector; reserve Complex as a visible disabled option.
- Reopen the same conversation when switching so history and agent identity remain intact.
- Correlate background tasks with their concrete child agent and spawning run/tool call.
- Show the current root's stored and live descendants in an Agent Map.
- Load a child's prompt, result and run facts only when its card is selected.

## Acceptance

- [x] Single removes subagent tools; Multi enables them without replacing the conversation.
- [x] Complex is visible but cannot be selected.
- [x] Agent Map reports the complete selected root tree and live background status.
- [x] Root and child cards expose summaries; child transcript detail is lazy.
- [x] Host and extension tests, packaging and packaged smoke pass.
