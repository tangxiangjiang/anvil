# p_0.46.83 — Expand Session Manager groups from the title bar

**Status:** done

## Goal

Give the Session Manager title bar an explicit way to reopen all collapsed
date groups, paired with VS Code's native Collapse All action.

## Scope

- Add an Expand All command to the `Anvil: Sessions` title bar.
- Expand every visible recency group without selecting or focusing a session.
- Keep the existing native Collapse All title action.
- Load the current session list first when expansion is requested before the
  lazy tree has been opened.

## Non-goals

- Replacing the native Tree View.
- Persisting a forced expansion state across VS Code windows.
- Opening session chat tabs while expanding groups.

## Tasks

- [x] Retain the native TreeView handle and expose provider-side expansion.
- [x] Contribute the title-bar command and icon.
- [x] Add regression coverage and package the synchronized patch release.

## Acceptance

- [x] The Sessions title bar exposes Expand All.
- [x] Expand All opens Today, This week, Earlier, and Undated when present.
- [x] Collapse All remains available through the native tree action.
- [x] Expanding groups does not open or select a session.
- [x] Extension tests and packaged smoke pass.
