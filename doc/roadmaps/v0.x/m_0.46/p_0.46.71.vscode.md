# p_0.46.71 — Reject structurally truncated final summaries

**Status:** done

## Goal

Prevent an agent run from reporting success when its `finish_task` summary
clearly stops at a section introducer or inside a fenced code block.

## Scope

- Reject final summaries ending in `:` or `：`.
- Reject final summaries with an unclosed Markdown code fence.
- Reuse the bounded finish-protocol correction and recovery path so the model
  must send a complete replacement before the run ends.

## Acceptance

- [x] A summary ending in `建议验证：` is not accepted as completion.
- [x] A summary containing an unclosed code fence is not accepted.
- [x] Complete summaries retain the existing completion behavior.
- [x] The 0.46.67 VSIX passes packaged smoke and installs locally.
