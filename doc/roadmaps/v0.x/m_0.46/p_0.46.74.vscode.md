# p_0.46.74 — Collapsible task plans with history

**Status:** done

## Goal

Make closing the live task plan reversible and keep earlier plans reachable in
the conversation that produced them.

## Scope

- Replace the task plan's destructive-looking `×` control with a collapse
  toggle that leaves the Plan header visible.
- Keep distinct task-plan revisions from the retained conversation transcript
  in a bounded history list below the current plan.
- Rebuild that list through the existing transcript replay path; add no new
  host protocol or persistent store.
- Keep status-only updates on the same history entry rather than duplicating
  the plan.

## Non-goals

- A workspace-wide plan archive independent of conversations.
- A new structured plan protocol or changes to plan-mode approval documents.
- Retaining plans older than the conversation records available from the store.

## Tasks

- [x] Add collapsible plan markup and theme-aware styling.
- [x] Collect, update, bound, and render plan history in the webview.

## Acceptance

- [x] Clicking the Plan header collapses the body but leaves a visible control
      that restores it.
- [x] Earlier distinct plans are listed newest-first and can be expanded.
- [x] Status-only changes update one plan entry.
- [x] Clearing the active list retains the history entry point.
- [x] Switching conversations clears the old conversation's plan history, and
