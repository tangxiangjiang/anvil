# p_0.46.31 — Fold the work, keep the summary

**Status:** done (2026-10-22)
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §34

## Goals

Make a completed turn collapse immediately, including the newest turn, while keeping its
`Summary` conclusion outside the fold and always readable.

## Scope

Reply/summary DOM placement, completion folding, rail resynchronization, focused unit tests
and documentation.

## Non-goals

- Changing Thinking or tool-card folding.
- Changing summary title/body extraction.
- Changing stored transcripts or the host protocol.

## Tasks

1. Hoist a marked Summary block from the reply body to immediately after its reply.
2. Recompute the folded body's rail after the Summary leaves it.
3. Force the current reply closed and release it when a live or replayed run completes.
4. Keep the Summary visible as the reply's sibling.
5. Compile, lint, test, package and smoke the VSIX.

## Acceptance

- [x] Summary title and body remain visible while the work above is folded.
- [x] The newest reply folds as soon as its run completes.
- [x] A completed reply folds even if it was open during streaming.
- [x] Live and replayed completions use the same rule.
- [x] Compile, lint, 524 unit tests, VSIX packaging and packaged smoke pass.
