# p_0.46.79 — Quote selected conversation text

**Status:** done

## Goal

Turn an explicit transcript selection into quote context without changing
ordinary text or image paste behavior.

## Scope

- Mark user and assistant narrative regions as selectable quote sources.
- Show a floating Quote action for a valid transcript selection.
- Add Quote selection and Copy to the selected-text context menu.
- Bind `Ctrl+Shift+Q` to quote the current transcript selection.
- Split a selection spanning messages into role-preserving quote chips.

## Non-goals

- Treating pasted clipboard text as an implicit quote.
- Quoting tool controls, headers, or composer UI.
- Persisting arbitrary browser ranges after the transcript changes.

## Tasks

- [x] Extract selected narrative text by message and role.
- [x] Add floating, context-menu, and keyboard actions.
- [x] Preserve ordinary paste and native unselected context behavior.
- [x] Add tests and package the synchronized patch release.

## Acceptance

- [x] Selecting narrative text exposes a Quote selection action.
- [x] Right-clicking a valid selection offers Quote and Copy.
- [x] `Ctrl+Shift+Q` produces the same quote chips.
- [x] Cross-message selections preserve each message's speaker.
- [x] Plain text and image paste behavior is unchanged.
- [x] Extension tests and packaged smoke pass.
