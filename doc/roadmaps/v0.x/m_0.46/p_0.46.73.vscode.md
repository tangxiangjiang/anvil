# p_0.46.73 — Checkpoints contain actual content changes

**Status:** done

## Goal

Show Undo only when a run actually changed file content, not merely because a
write tool was attempted or source control changed a file's writable state.

## Scope

- Compare every captured pre-image with the post-run bytes.
- Drop unchanged files and paths a failed create never produced.
- Remove the run checkpoint entirely when no captured file changed.
- Preserve modified, created, and deleted files with the existing safe-restore
  post-state checks.

## Acceptance

- [x] A failed Patch does not produce an Undo card.
- [x] A mode-only change such as `p4 edit` is not reported as a content edit.
- [x] Mixed runs retain only files whose contents changed.
- [x] The 0.46.69 VSIX passes packaged smoke and installs locally.
