# p_0.46.44 — A persistent neutral diagram action

**Status:** done
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §47

## Goals

Keep a diagram's large-view action easy to find without covering diagram content.

## Scope

- Place View above the diagram frame at its upper-right edge.
- Keep it visible at rest with reduced opacity.
- Use neutral VS Code toolbar/widget colours instead of the blue primary-button colour.
- Preserve hover, focus and keyboard activation.

## Acceptance

- [x] View never overlaps the rendered diagram.
- [x] View remains visible without hover and becomes fully opaque on interaction.
- [x] The control follows VS Code theme colours and retains a visible focus ring.
- [x] Compile, lint, 627 tests, package and packaged smoke pass.
