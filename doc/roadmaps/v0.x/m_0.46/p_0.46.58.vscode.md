# p_0.46.58 — Configurable subagent profiles

**Status:** done

## Goal

Let a workspace define reusable subagent specializations and let the main agent
choose the appropriate profile through the ordinary `spawn_agent` tool call.

## Scope

- Strict, versioned `.anvil/subagents.json` parsing and atomic host-owned CRUD.
- Profile-aware foreground and background subagent resolution.
- Profile management inside the Models Manager.
- SDK, host protocol, extension, and packaged-VSIX coverage.

## Acceptance

- [x] Invalid or malformed profiles do not consume agent budget or get overwritten.
- [x] Explicit spawn fields override profile defaults without widening parent safety.
- [x] The Models Manager can add, edit, remove, and open workspace profiles.
- [x] Runtime, host, extension tests and packaged smoke pass.
