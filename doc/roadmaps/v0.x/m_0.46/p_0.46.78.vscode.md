# p_0.46.78 — Collapsed Plan leaves only its edge handle

**Status:** done

## Goal

Remove the empty Plan title frame when the task plan is collapsed while
keeping a discoverable way to expand it.

## Scope

- Collapse the Plan container to zero visual height.
- Hide its title and saved count while collapsed.
- Restore the composer's complete top corners and standalone focus treatment.
- Keep the edge handle visible with an action tooltip.

## Non-goals

- Expanded Plan layout or history changes.
- Custom tooltip infrastructure.
