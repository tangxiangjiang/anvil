# p_0.46.48 — Return to latest conversation

**Status:** done

## Goal

Provide a compact, discoverable way to return a long transcript to its newest content.

## Scope

- Show a floating latest-message button only while the transcript is away from its bottom.
- Place it above the composer without changing the composer's measured height.
- Scroll directly to the transcript bottom when activated.
- Use a labelled, keyboard-focusable, VS Code-themed icon button.

## Acceptance

- [x] The button is hidden at the bottom and appears after scrolling upward.
- [x] Activating it moves the conversation to its latest content.
- [x] It does not change the composer or transcript reservation height.
- [x] Unit tests, packaging and packaged smoke pass.
