# p_0.46.36 — Readable and zoomable diagrams

**Status:** done (2026-10-22)

## Goals

Make dense Mermaid diagrams readable without making the inline transcript excessively wide.

## Scope

- Use regular-weight diagram labels and medium-weight group titles.
- Make an inline diagram keyboard- and pointer-openable.
- Provide a modal viewport with zoom out, fit, zoom in, scrolling, Escape and close.

## Acceptance

- [x] Node and edge labels are not bold.
- [x] Clicking or pressing Enter/Space on a diagram opens the large view.
- [x] The large view supports zoom and two-dimensional scrolling.
- [x] Escape and the close control dismiss it.
- [x] Compile, lint, 528 unit tests, packaging and packaged smoke pass.
