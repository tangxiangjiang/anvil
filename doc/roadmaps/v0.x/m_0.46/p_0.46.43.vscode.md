# p_0.46.43 — Quote a conversation message

**Status:** done
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §46

## Goals

Let a user point the next prompt at an earlier user or assistant message without copying and
pasting it by hand.

## Scope

- Put a compact quote action beside user messages and completed assistant answers.
- Let the composer's add menu and `/ref ` open the same list of messages.
- Show selected messages as removable composer chips.
- Send quoted text through prompt context with a bounded host-side representation.
- Preserve replay, keyboard navigation, screen-reader labels and text-only DOM construction.

## Acceptance

- [x] A message quote action adds that message once and focuses the composer.
- [x] The add menu and `/ref ` expose the same newest-first message list.
- [x] Quotes can be removed before sending and are echoed on the sent turn.
- [x] The host labels quoted user and assistant text and applies the prompt-context budget.
- [x] Compile, lint, 627 extension tests, targeted host tests, package and packaged smoke pass.
