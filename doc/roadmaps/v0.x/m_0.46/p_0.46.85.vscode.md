# p_0.46.85 — Archive and restore sessions

**Status:** done

## Goal

Let completed or inactive conversations leave the recency lists without being
deleted, while remaining available under an Archived group.

## Scope

- Add Archive Session and Unarchive Session context-menu actions.
- Persist archived agent ids in VS Code workspace state.
- Remove archived sessions from Today, This week, Earlier, and Undated.
- Show archived sessions under a dedicated Archived group.
- Keep archived conversations openable, renameable, forkable, and deletable.
- Carry an archived parent's subagent descendants with its tree.

## Non-goals

- Deleting or rewriting transcript JSONL.
- Synchronizing archive state across unrelated workspaces.
- Adding a host protocol method or store record for an editor-only filing
  preference.

## Tasks

- [x] Partition active and archived session trees in the pure list model.
- [x] Persist and prune workspace-local archive ids.
- [x] Add archive and restore commands and context menus.
- [x] Add regression coverage and package the synchronized patch release.

## Acceptance

- [x] Archiving removes a session from its recency group.
- [x] Archived lists the session without deleting its transcript.
- [x] Unarchive returns it to the appropriate recency group.
- [x] Parent and subagent hierarchy remains intact.
- [x] Extension tests and packaged smoke pass.
