# p_0.46.46 — Natural-size themed flowcharts

**Status:** done
**Milestone:** [m_0.46_editor_polish.vscode.md](../m_0.46_editor_polish.vscode.md)
**Linked design:** [46-editor-polish.vscode.md](../../../design/v0.x/46-editor-polish.vscode.md) §49

## Goals

Keep small flowcharts at their natural Mermaid size and prevent authored fill colours from
creating unreadable theme-breaking blocks.

## Scope

- Size inline diagrams from their SVG viewBox instead of stretching every graph to the column.
- Fit diagrams larger than the Context surface into a complete inline thumbnail.
- Keep natural-size detail, zoom and pan in View.
- Normalize node and cluster fills after Mermaid's inline styles are applied.
- Preserve the large-view zoom and pan behavior.

## Acceptance

- [x] A short vertical flowchart is not enlarged to the reading-column width.
- [x] Dense diagrams shrink proportionally so their complete topology is visible inline.
- [x] Authored bright node fills cannot produce low-contrast labels in dark mode.
- [x] The normalized appearance is retained in large view.
- [x] Compile, lint, 628 tests, package and packaged smoke pass.
