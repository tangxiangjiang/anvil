## Goal

Render fenced `mermaid` blocks as diagrams in chat and focus-view Markdown.

## Scope

- Vendor Mermaid with the extension; no CDN or network access.
- Render only after a fence closes, so streaming does not restart diagram layout per token.
- Display the generated SVG as a data-image rather than injecting model-produced markup.
- Keep the fenced source as the fallback when Mermaid is absent or rejects the graph.

## Acceptance

- [x] A closed `mermaid` fence renders as a diagram.
- [x] An open/invalid fence remains readable source.
- [x] Rendering works under the existing CSP without network access.
- [x] The supplied flowchart shape is covered as a fixture.
