# p_0.46.66 — Per-turn queued model and mode

**Status:** done

## Goal

Let a reader choose the model and permission mode for an Enqueue or Steer
message while the current response is still running.

## Scope

- Keep the model selector and permission-mode menu enabled during a run.
- Stage a mid-run selection without changing the run already in flight.
- Snapshot model and permission mode onto every queued or priority turn.
- Apply that snapshot after the active run reaches a terminal state and before
  the queued prompt is sent.

## Acceptance

- [x] Model and mode remain selectable while a response runs.
- [x] The active response keeps its original model and permissions.
- [x] Enqueued and Steer messages run with the options selected when sent.
- [x] Extension tests, packaged smoke, and local installations pass.
