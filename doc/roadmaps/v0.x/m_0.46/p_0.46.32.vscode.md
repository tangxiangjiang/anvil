# p_0.46.32 — Keep token units and directions apart

**Status:** done (2026-10-22)

## Goal

Keep the animated live meter readable as `8.3M in · 37k out`, never `8.3Min · 37kout`.

## Scope

Use a non-collapsing gap between each compact count and its `in`/`out` direction, and give
that gap stable width while the travelling character animation owns the line.

## Acceptance

- [x] `M in` and `k out` remain visibly separated during and after animation.
- [x] Reduced-motion text keeps the same separation.
- [x] Compile, lint, 524 unit tests, packaging and packaged smoke pass.
