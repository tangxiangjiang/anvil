# p_0.46.77 — Agent Map root uses the conversation model

**Status:** done

## Goal

Show the model selected in the current conversation on Agent Map's root node
instead of a stale model from the persisted session listing.

## Scope

- Use the same effective model source for the composer picker and Agent Map
  root node.
- Override only the selected conversation's root; child agents keep their own
  recorded models.
- Cover explicit, resolved, and workspace-default model selection.

## Non-goals

- Changing a child agent's model or subagent profile.
- Rewriting historical run metadata.
- Agent Map layout changes.

## Tasks

- [x] Accept an explicit root model when building Agent Map.
- [x] Share current-model resolution between the picker and Agent Map.
- [x] Add regression tests and package the synchronized patch release.

## Acceptance

- [x] Selecting Claude Sonnet in the conversation shows Claude Sonnet on the
      Agent Map root.
- [x] Child nodes continue to show their own session models.
- [x] Workspace default and host-resolved models remain valid fallbacks.
- [x] Extension tests and the packaged 0.46.73 smoke pass.
