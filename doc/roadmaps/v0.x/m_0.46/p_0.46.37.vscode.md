## Goals

Render Mermaid-shaped code even when the fence lacks a language, and make dense class and
architecture diagrams quieter and less cramped.

## Scope

- Detect standard Mermaid diagram declarations in unlabelled or `text` fences.
- Use a restrained editor-matched base theme.
- Remove heavy node shadows and borders; reduce class-member type weight and size.
- Keep explicit non-Mermaid language fences as code.
