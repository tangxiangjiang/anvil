# p_0.46.65 — Docked collapsible plan

**Status:** done

## Goal

Keep the current plan immediately above the composer without allowing it to
cover the bottom of the conversation.

## Scope

- Render the current plan in the measured composer dock instead of appending
  its review card to the transcript.
- Show the plan prose and its existing open, approve, and keep-planning actions.
- Let the reader collapse the plan to a compact label and expand it again.
- Bound long plan prose with an internal scroll area.

## Acceptance

- [x] The transcript bottom ends above an expanded or collapsed plan.
- [x] The plan toggles between its full review surface and one compact label.
- [x] Plan actions and Markdown rendering remain available.
- [x] Extension tests, packaged smoke, and local installations pass.
