# p_0.46.90 — Source selection chat references

**Status:** done

## Goal

Let a user attach exact source lines to an Anvil chat from the editor.

## Scope

- Add an editor context-menu command and Windows/Linux/macOS keyboard shortcut.
- Capture the selected file, one-based line range, and text before editor focus changes.
- Reveal the most recently used chat and show a removable source-reference chip.
- Keep the frozen selection attached to its queued turn.

## Acceptance

- [x] A non-empty file selection can be added from the editor context menu.
- [x] `Ctrl+Alt+L` (`Cmd+Alt+L` on macOS) invokes the same command.
- [x] The composer shows and can remove a `path:start-end` reference.
- [x] Sending or enqueueing uses the captured text and clears only that submitted chip.
- [x] Empty and non-file selections do not create a chat.
- [x] Extension tests and packaged smoke pass.

## Non-goals

- Extending `@` mentions with line-range syntax.
- Keeping the reference synchronized with later source edits.
- Adding multiple simultaneous source selections.
