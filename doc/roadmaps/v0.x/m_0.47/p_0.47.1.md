# p_0.47.1 — The audit

**Status:** done
**Milestone:** [m_0.47_evaluation_and_audit.md](../m_0.47_evaluation_and_audit.md)
**Linked design:** [47-evaluation.md](../../../design/v0.x/47-evaluation.md) §7

## Goals

Read the whole agent path once and write down what is wrong with it, with a failing test
beside each claim. The output is a list, not a set of fixes: fixes land as plain commits, and
what this phase guarantees is that each one is pinned by a test that existed before it.

## Scope

`doc/roadmaps/v0.x/m_0.47/audit.md` (new), and test files beside the code each finding names.
No non-test source file changes in this phase, except the fix commits that follow it.

The files read, in this order: `source/agent.go`, `run.go`, `runs.go`, `subagent.go`,
`workflow.go`, `tasks.go`, `checkpoints.go`, `fork.go`, `internal/runtime/*.go`,
`internal/llm/*.go`, `internal/tools/*.go`, `internal/permissions/*.go`,
`internal/checkpoint/*.go`.

## Tasks

1. **Read with four questions.** For every function on the path: can it leave state
   inconsistent on error; can a model-supplied value reach a boundary (path, shell, URL,
   schema) unvalidated; can an error be swallowed; does the code match the design chapter that
   describes it.
2. **Write the list.** One entry per finding: severity (`bug` / `gap` / `doc`), file and
   line, the sentence that states the defect, and the name of the test that reproduces it.
3. **Write the tests.** One `Test…` per `bug` or `gap`, in the package it concerns, failing
   on the current tree. Mark each `t.Skip("audit: open, see audit.md #N")` so that the suite
   stays green until the fix lands and the skip is removed in the same commit.
4. **Record the suspicions.** A finding the author could not reduce to a test goes under
   *Suspicions* with what information would settle it.
5. **Verify.** The Go suite from Git Bash; `go vet`; reconcile the audit skip inventory
   with open findings and separately recorded race/cgo evidence skips.

### Gate

- 命令：`cd source && go vet ./... && go test -count=1 ./... && git grep -n 'audit: open' -- '*_test.go'`
- 通过条件：`go vet` 和 `go test` 为零退出码；跳过清单与 `audit.md` 一致：一个 *open* 设计冲突（#10），另有两个已记录的 race/cgo 证据测试（#20/#30）。每个 *fixed* 发现都有修复前失败、修复后通过的验证证据；涉及 race 的证据来自移除对应 skip 的隔离 Linux 工作副本。
- 失败条件：任一 *fixed* 发现没有复现测试或修复前失败证据；有未记录的审核 skip；或将证据测试 skip 算成新的 open 缺陷。不要在当前工作树通过 stash 修复来复现，使用对应历史版本的隔离工作副本。
- 基线条目：`go vet ./...` 的警告数（当前应为 0）；`go test -count=1 ./...` 的用时；`audit.md` 中 `bug` / `gap` / `doc` 三类的计数。

## Acceptance

- [x] `audit.md` lists every finding with severity, location, statement and test name.
- [x] Every `fixed` finding has evidence of its test failing before the fix and passing after.
- [x] The open finding's test is skipped by name; the two race/cgo evidence skips are separately recorded.
- [x] *Suspicions* names, for each entry, what would settle it.
- [x] `cd source && go build ./... && go vet ./... && go test -count=1 ./...` is green (run
      from Git Bash).

## Delivery evidence

The audit and ordinary fix commits are recorded in [audit.md](audit.md). The final audit
race run with skips removed recorded 29 passes and one expected failure for the open
policy-conflict test (#10), and no races. Current default tests retain the #10 policy skip
and unconditional #20/#30 race/cgo evidence skips. The audit phase is complete; that remaining
policy decision is not silently resolved by the evaluation harness.

## Non-goals

- Fixing findings inside this phase's commit.
- Refactoring code that is correct but could be clearer; that is a `doc` finding at most.
- Reading the host, the worker, the gateway or the editor.
