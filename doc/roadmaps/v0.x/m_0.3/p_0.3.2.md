# Phase p_0.3.2 — MCP stdio integration

**Status:** done

## Goals

Attach MCP stdio servers so their tools join the agent registry.

## Scope

- `Options.MCPServers` map: name → `{Command, Args, Env}`
- On Create/Resume: start servers, `tools/list`, wrap each as `mcp_<server>_<tool>`
- On Close: shut down MCP processes
- Secrets in Env are caller-owned; not written to JSONL store

## Non-goals

- MCP HTTP/SSE transport (may follow later)
- Dynamic tool list refresh mid-run

## Tasks

1. Add MCP client (`internal/mcp`, JSON-RPC + Content-Length over stdio).
2. Bridge MCP tools into Registry.
3. Lifecycle: start on Create/Resume, stop on Close.
4. Tests with `internal/mcp/fakecmd` fake server.

## Acceptance

- [x] At least one MCP stdio tool is callable in tests (fake server).
- [x] Close terminates the child process.
- [x] Resume requires re-passing MCPServers (not loaded from store).
