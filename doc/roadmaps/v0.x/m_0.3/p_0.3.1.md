# Phase p_0.3.1 — Custom tool API

**Status:** done

## Goals

Allow callers to register custom tools alongside built-ins.

## Scope

- Public `ToolSpec` / `ToolHandler` on `Options.Tools`
- Merge into registry at Create/Resume; name collision with built-ins or duplicates → create-time error
- Custom tools appear in LLM tool list and execute via the normal loop

## Non-goals

- MCP
- Permission hooks
- Context compression

## Tasks

1. Define public tool registration types on Options.
2. Extend `internal/tools.Registry` to register external tools safely.
3. Wire Create/Resume.
4. Unit test: custom tool called in mock loop; collision fails Create.

## Acceptance

- [x] Custom tool appears in model tool list and executes.
- [x] Duplicate name with built-in fails at Create with non-retryable error.

## Depends-on

- Milestone 0.2.1 done
