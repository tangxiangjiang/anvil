# Phase p_0.3.4 — Context compression

**Status:** done

## Goals

Compress long histories so sessions stay within a char budget.

## Scope

- Options: `HistoryMaxChars`, `HistoryKeepRecent`
- Before the tool loop: if over budget, summarize older messages; keep recent N
- Summarization via Completer when available; deterministic fallback otherwise
- Resume reloads full JSONL and re-applies compression on the next Send

## Non-goals

- Perfect token counting
- Multi-level hierarchical memory

## Tasks

1. Implement `internal/compress`.
2. Wire into runtime Loop.
3. Tests with oversized fake history.

## Acceptance

- [x] Oversized history is summarized / trimmed without losing recent turns.
- [x] Under-budget history is unchanged.
