# p_0.40.10 — Input and panel affordances

**Status:** done (2026-10-19)
**Milestone:** [m_0.40_editor_alignment.vscode.md](../m_0.40_editor_alignment.vscode.md)
**Linked design:** [40-editor-alignment.vscode.md](../../../design/v0.x/40-editor-alignment.vscode.md), [35-vscode-extension.vscode.md](../../../design/v0.x/35-vscode-extension.vscode.md)

## Goals

1. **Escape interrupts.** The composer cancels the running turn; the Stop button stays.
2. **Files can be dropped and images chosen.** A drop becomes mention chips or image attachments;
   a picker offers what paste already accepts.
3. **Prompts can be recalled.** Up and Down walk the prompts already sent in this session.
4. **An answer can be copied, and the run's state is visible from anywhere.** A copy action on
   assistant messages and a status-bar item that opens the chat.

## Scope

`editors/vscode/media/chat.js`, `media/chat.css`, `media/history.js` (new), `src/chatPanel.ts`,
`src/chatStatus.ts` (new), `src/statusBar.ts` (new), `src/hub.ts`, `src/extension.ts`,
`src/attachments.ts`, `package.json`, tests and docs.

## Tasks

1. **Escape.** A keydown listener on the window cancels when a run is active and does nothing
   otherwise. It is on the window because the textarea is disabled while a turn runs; an idle
   Escape still closes the palette and never touches the draft. The Stop button and Escape share
   one `requestStop`.
2. **Drag and drop.** Dropping an image adds it through the same `FileReader` a paste uses;
   every other file is posted to the host as plain paths and/or `file:` URIs and resolved there
   with `relativeMention`, because the workspace root is the extension's to know. A file outside
   the workspace is reported, not silently dropped; a drop carrying no path at all says to use
   `@`. The whole panel is the target, with a focus-coloured outline while a file drag is over it.
3. **Image picker.** An **Image** button beside `@` posts `pickImages`; the extension opens
   `showOpenDialog` filtered to `png/jpg/jpeg/gif/webp`, reads the files with
   `vscode.workspace.fs.readFile`, and answers with `data:` URLs — the representation a paste
   leaves in the composer. `dataUrlFromBytes` applies the paste path's own encoded-size cap, so a
   file cannot be attachable one way and refused the other.
4. **History.** `media/history.js` holds the list, the cursor and the borrowed draft as a plain
   global (like `meter.js`), so the cursor arithmetic is tested without a document. Up acts only
   with the caret at the first character, Down only at the last, so the arrows still move through
   a multi-line draft. The list is cleared with the transcript and repopulated by the replay,
   which makes recall work in a reloaded tab; a repeat of the preceding prompt is one entry.
5. **Copy.** Every assistant bubble gets a quiet **Copy** when its round ends — including a round
   ended by a tool call — carrying the raw Markdown. The write goes through
   `vscode.env.clipboard.writeText`; nothing near it is HTML.
6. **Status bar.** `src/chatStatus.ts` decides the window's phase from every tab (`waiting`
   outranks `running`) and the item's text and tooltip; `src/statusBar.ts` builds the one item and
   redraws it on `onRunningChanged`/`onTabsChanged`. Its command `anvil.focusChat` calls
   `hub.revealChat()`: the waiting tab, else the front tab, else any open tab, else a new one.
   The panel tells the hub when an approval arrives, is answered, is withdrawn, or is settled by
   a rule it just wrote (`Session.forgetApproval`), so the item cannot keep saying "waiting".
7. Tests and docs.

  (`test/unit/inputAffordances.test.ts`: the window listener is guarded by `!running`, calls

  (`test/unit/promptHistory.test.ts`, 9 cases: order, both ends, draft restore, dedupe, the cap,

  `chatPanel.copy` calls `vscode.env.clipboard.writeText`; no `innerHTML` in `addCopy`.)
- [x] The status bar reflects idle / running / waiting and opens the chat on click.
  (`test/unit/chatStatus.test.ts`: `phaseOf` across tabs and order, waiting over running, the
  three texts; the hub reads the panels and `revealChat` exists; the item is one, and the
  command is contributed.)
- [x] `npm test` green (369 tests).

## Non-goals

- Multi-line editing chords, Vim bindings, or a rich-text composer.
- Global (cross-session) prompt history on disk.
- Dragging text selections into the panel.
- A status-bar item per tab.
- Resolving a dropped file's path by asking the user when the drag carries none — the panel says
  to use `@` instead.
