# Milestone 0.20 — Agent plugins (worker-side)

**Status:** done  
**Product version:** 0.20.x

## Goals

Introduce a **plugin Host + load policy** on agent-worker (and in-process Options), with in-tree and exec-stdio plugins registering tools under cwd sandbox. Daemon only allowlists and advertises capabilities.

**Principle:** general agent capabilities stay in core; plugins are optional/heavy/org-specific only ([20](../../design/v1.0/20-plugins.md)).

## Overall acceptance

1. Worker job with `plugins: [<sample>]` exposes sample tool to the model; without plugin id tool absent.
2. Exec plugin crash does not kill agentd; worker reports error / respawn policy documented.
3. Plugin denied by daemon policy cannot load even if job requests it.
4. In-process `Options.Plugins` loads the same in-tree sample.
5. No marketplace / .so Go plugin requirement.

## Non-goals

- Marketplace
- Plugins inside agentd process
- Re-implementing all of 0.16–0.19 as plugins in this milestone (one sample enough)

## Depends-on

- Prefer 0.11 agent-worker skeleton; in-process path can ship first if 0.11 incomplete
