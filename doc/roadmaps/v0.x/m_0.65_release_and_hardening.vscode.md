# Milestone 0.65 — Release, production hardening, and audit-only Web

**Status:** planned

Finish the VS Code requirement-to-release path, qualify it for production, and enforce Web as a
read-only audit application. Design:
[65](../../design/v0.x/65-release-and-hardening.vscode.md).

## Goals

1. Add immutable release candidates, explicit promotion/publication, recovery, and rollback intent.
2. Qualify the full 0.60–0.64 path with fault, soak, scale, diagnostics, telemetry, and platform
   gates.
3. Complete migrations/provenance/rollback and remove every Web Chat/config/workflow mutation.

## Overall acceptance

- One explicit VS Code path reaches the configured release state from an approved requirement.
- Partial publication, retries, restart, and rollback preserve one durable outcome.
- Required platform/fault/soak/privacy/migration/provenance/package gates pass.
- Administrative workflow/configuration is available through authenticated VS Code or CLI.
- Automated UI/route tests prove Web exposes audit reads/exports only.

## Non-goals

- Automatic release on green CI.
- Remote Worker enrollment, placement, and execution (0.66).
