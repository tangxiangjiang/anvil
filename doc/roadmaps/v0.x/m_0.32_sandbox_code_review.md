# Milestone 0.32 — Sandbox code review + VS Code Server

**Status:** done

## Goals

- Read file + git status/diff over cluster edge (sandbox-confined).  
- anvil-web read-only workbench: tree, viewer, Changes/diff.  
- ~~agentd launches **VS Code Server** for a project directory~~ — **deferred** (p_0.32.3), not delivered.  
- ~~**Ingress:** fixed nginx → node → agentd **ide-proxy**~~ — deferred with p_0.32.3.  
- ~~**IDE auth:** anvil-web session~~ — deferred with p_0.32.3.  
- Explicit non-goal: web code editing, git write UX, or per-session nginx reloads.

The milestone is `done` for what it delivered: p_0.32.1 and p_0.32.2. p_0.32.3 was cut by a
product decision and has no code behind it (nothing in `source/` starts or proxies a code
server); it stays `deferred` as its own phase and is not part of this milestone's acceptance.

## Overall acceptance

1. An operator can read a file and see `git status` / `git diff` of a sandbox-confined project
   over the cluster edge (p_0.32.1).
2. The anvil-web workbench shows the tree, a file viewer and Changes/diff, read-only (p_0.32.2).
3. The web side never writes a file and never starts a process on a worker.

## Non-goals

- **VS Code Server, ide-proxy and IDE auth (p_0.32.3):** deferred by product decision, not built.
  Reviving it is a new, separately scheduled phase; the design stays in chapter 32.
- Web code editing, git write UX, per-session nginx reloads.
