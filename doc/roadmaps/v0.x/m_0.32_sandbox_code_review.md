# Milestone 0.32 — Sandbox code review + VS Code Server

**Status:** in_progress
**Product version:** 0.32.x

## Goals

- Read file + git status/diff over cluster edge (sandbox-confined).  
- anvil-web read-only workbench: tree, viewer, Changes/diff.  
- agentd launches **VS Code Server** for a project directory configured like workers (sandbox path + optional git).  
- **Ingress:** fixed nginx → node → agentd **ide-proxy** (dynamic sid→port); code-server loopback + `--auth none`.  
- **IDE auth:** anvil-web session (same login as console); not a code-server password.  
- Explicit non-goal: web code editing, git write UX, or per-session nginx reloads.
