# Phase p_0.13.1 — Chunker and on-disk index

**Status:** done

## Goals

Walk cwd, chunk files, write `.anvil/index/` meta + chunks (no vectors yet).

## Scope

- Language-agnostic chunker (size/overlap lines)
- `files.jsonl` / `chunks.jsonl` / `meta.json`
- Skip denylist (`.env`, binaries, huge files)
- `internal/index` package

## Non-goals

- Search tool
- Embeddings

## Tasks

1. Chunker unit tests.
2. Build index on fixture tree.
3. Incremental hash skip for unchanged files.

## Acceptance

- [x] Rebuilding twice without edits does not rewrite chunk hashes unnecessarily.
- [x] Escaped/symlink files outside cwd are not indexed.
