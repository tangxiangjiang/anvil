# Milestone 0.52 — Agent mode bridge

**Status:** planned
**Product patch:** none. Roadmap milestone 0.52 is not a VS Code plugin patch. Each actual
user-visible delivery batch must increment the then-current `editors/vscode/package.json`
patch by exactly one; these planned documents do not select or reserve that patch.

## Goals

1. Carry the SDK's Single, Multi, and Complex modes through the editor-host protocol.
2. Let VS Code select and persist a conversation's mode without mutating a running turn.
3. Render Complex stages, structured briefs, and acceptance outcomes as understandable,
   replay-safe conversation UI.

## Ordering

p_0.52.1 establishes the wire and host contracts. p_0.52.2 persists and applies those contracts
per conversation. p_0.52.3 depends on both so live and replayed Complex events share one
representation and the selected mode is already stable.

## Overall acceptance

1. Protocol round-trip tests preserve Single, Multi, and Complex values and reject unknown
   values without silently falling back.
2. Host tests prove a mode is applied at session creation/resume and is not changed midway
   through an active run.
3. Extension tests prove mode selection survives reload and remains scoped to its conversation.
4. Complex live and replay fixtures show Decision, Analyze, Worker fan-out, briefs, dependencies,
   and each acceptance item's reported state.
5. Single-mode sessions retain their existing wire and UI behavior when no mode is specified.
6. Run `cd source && go test ./...` and `cd editors/vscode && npm test`; before each actual
   user-visible delivery batch, bump the current plugin patch once, then package and run the
   packaged VSIX smoke test.

## Non-goals

- Implementing SDK agent modes or changing their orchestration semantics.
- Automatic mode routing or changing mode during a running turn.
- A new scheduler, reviewer stage, or cross-workspace stage execution.
- Assigning a VS Code plugin patch while this milestone remains documentation-only.
