# Phase p_0.2.3 — Interactive multi-turn example

**Status:** done

## Goals

Ship an example that demonstrates Resume + multi-turn local use.

## Scope

- `source/examples/interactive` CLI: create or `--resume <agentID>`, loop stdin prompts, print stream events, print agent id for resume
- README snippet for interactive usage
- Ctrl+C cancels the in-flight run via `Run.Cancel`

## Non-goals

- Full TUI / bubbletea UI
- Web UI

## Tasks

1. Implement interactive main.
2. Document env vars + resume flow.
3. Manual smoke checklist in this phase.

## Acceptance

- [x] User can run two turns in one process with shared history.
- [x] User can exit, `Resume` same id in a new process, continue.
- [x] Example builds from `source/` (`go build ./examples/interactive`).

## Manual smoke

```bash
cd source
export ANVIL_API_KEY=...
export ANVIL_BASE_URL=...
export ANVIL_MODEL=...
go run ./examples/interactive .
# send two prompts, note agent id, exit
go run ./examples/interactive --resume agent-<id> .
```
