# Milestone 0.2 — Resume and observability

**Status:** done  
**Product version:** 0.2.x

## Goals

- Persist agents under `{cwd}/.anvil/` (JSONL).
- Support `Resume(agentID)`.
- `Cancel`, `MaxSteps` / `MaxWallTime` as first-class controls.
- Richer `RunResult` (steps, usage) and `examples/interactive`.

## Overall acceptance

1. Kill process after a run; `Resume` same ID and follow-up `Send` retains history.
2. Cancel stops in-flight shell/LLM where supported.
3. Interactive example demonstrates multi-turn local use.

## Non-goals

- MCP / custom tools / approval hooks (→ 0.3)
- Cloud
- SQLite migration (unless JSONL blocked)
