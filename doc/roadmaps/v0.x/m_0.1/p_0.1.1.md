# Phase p_0.1.1 — Repository skeleton and public API types

**Status:** done

## Goals

Initialize the Go module under `source/` and compile-able public API surface.

## Scope

- `source/go.mod` (module path placeholder `github.com/anvil-dev/anvil`; **all Go code lives under `source/`**)
- Public files under `source/`: `agent.go`, `options.go`, `run.go`, `errors.go`, `types.go`
- Types and function signatures for Create / Prompt / Send / Stream / Wait / Close
- Stub bodies returning clear `ErrNotImplemented` or minimal no-op where needed so `go build ./...` succeeds in `source/`
- Empty `source/internal/` package dirs or placeholders as needed for imports

## Non-goals

- Real LLM calls, tools, or runtime loop
- Examples beyond ensuring the module builds
- Resume / store
- Go sources at repo root (must be under `source/`)

## Tasks

1. Create `source/go.mod` and package `anvil`.
2. Define `Options`, `LocalOptions`, `Model`, `Agent`, `Run`, `RunResult`, `Event`, `Error`.
3. Stub `Create`, `Prompt`, `(*Agent).Send`, `(*Run).Stream`, `(*Run).Wait`, `(*Agent).Close`.
4. Ensure `go build ./...` succeeds from `source/`.

## Acceptance

- [x] `go build ./...` succeeds from `source/` on a clean checkout.
- [x] Exported API names match design 02 for 0.1.
- [x] No network calls in this phase.
- [x] No `.go` / `go.mod` at repository root.

## Depends-on

None (first phase).
