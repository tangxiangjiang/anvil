# p_0.60.2 — VS Code Product workbench and artifact Chat

**Status:** planned

## Goals

Create, review, and approve requirements in VS Code using the existing mature Chat system.

## Scope

- Add the Product function group, project selector, requirement tree, editor, compare, and audit.
- Add create/import/revise/submit/approve/reject/supersede commands with revision-bound previews.
- Attach requirement identity/revision/provenance to Chat context and proposed artifact patches.
- Require visible diff approval before model-proposed content mutates the artifact.
- Add signed expiring Web/audit-to-VS Code artifact and Session handoff.
- Restore selected artifact, draft, Session tab, and event cursor after reload/reconnect.

## Tasks

1. Build Product navigation, requirement documents, commands, compare, and audit views.
2. Wire revision-bound artifact references and reviewed Chat patch application.
3. Add handoff, reload/reconnect, accessibility, stale-save, and duplicate-tab tests.

## Acceptance

- A keyboard/screen-reader path covers create → review → approve.
- Chat cannot mutate or approve an artifact and JSONL is not the requirement store.
- Stale editor saves show the current revision and reviewable conflict.
- Repeated handoff activates the same Session/artifact tab.
- Passive navigation and approval start no plan or execution.

## Non-goals

- Planning, execution, or hosted VS Code transport.

## Depends-on

- p_0.60.1 and the delivered VS Code Chat/Session system.
