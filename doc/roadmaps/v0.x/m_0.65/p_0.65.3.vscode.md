# p_0.65.3 — Migration, provenance, rollback, and audit-only Web

**Status:** planned

## Goals

Ship reproducible upgrade-safe artifacts and enforce Web as read-only audit only.

## Scope

- Add reproducible Host/VSIX/service artifacts, hashes, signatures, SBOM/provenance, and report.
- Test clean install, N-2 upgrade, restart-safe migration, downgrade refusal, and rollback drills.
- Move remaining cluster/Worker/model/secret/permission/organization configuration to VS Code/CLI.
- Remove/reject every Web Chat, configuration, workflow, approval, execution, provider, and release
  mutation; retain audit search/detail/redacted evidence/export and Open in VS Code.
- Add automated Web route/DOM/bundle tests and complete requirement-to-release packaged smoke.

## Tasks

1. Build reproducible signed artifacts, provenance reports, migrations, and rollback fixtures.
2. Move remaining administration to VS Code/CLI and remove/reject every Web mutation.
3. Run Web read-only, N-2 upgrade, clean package, full-flow smoke, and rollback gates.

## Acceptance

- Artifact/embedded Host/SDK/docs/metadata versions and hashes agree.
- Upgrade/rollback fixtures preserve or explicitly refuse every schema.
- Supported clean packaged smoke and provenance gates pass.
- Web exposes audit reads/exports only; stale mutation requests return a stable read-only error.
- VS Code/CLI provide the authenticated administration paths removed from Web.

## Non-goals

- Deleting historical audit records or remote Worker execution.

## Depends-on

- p_0.65.1 and p_0.65.2.
