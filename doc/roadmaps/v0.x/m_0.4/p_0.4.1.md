# Phase p_0.4.1 — Provider SSE streaming

**Status:** done

## Goals

Stream assistant text deltas from OpenAI-compatible and Anthropic APIs.

## Scope

- `llm.StreamCompleter` with `CompleteStream`
- Runtime emits incremental `assistant` events when the completer streams
- Tool-call assembly from streamed chunks
- interactive/oneshot already print `assistant` events as they arrive

## Non-goals

- Changing public Wait semantics
- Binary event protocols

## Tasks

1. Add SSE parsers for both providers.
2. Wire runtime emit deltas.
3. Tests with httptest chunked bodies.

## Acceptance

- [x] Consumer sees multiple assistant deltas before done.
- [x] Tool-calling runs still finish correctly.

## Depends-on

- Milestone 0.3 done
