# Phase p_0.6.4 — Store interface + optional SQLite

**Status:** done

## Goals

Keep JSONL as default; allow SQLite for larger sessions with one code path for Create / Resume / List / Get.

## Scope

- Extract store backend interface: Append, Load, ListIDs, Exists, Path/Dir as needed
- JSONL remains default implementation
- SQLite backend under `{cwd}/.anvil/agents.db` (single DB, agents keyed by id)
- `LocalOptions.Store` (or `StoreBackend`) = `jsonl` | `sqlite` (default jsonl)
- No automatic JSONL → SQLite migration (document only)
- Update design 06

## Non-goals

- Multi-machine sync
- Encryption at rest
- Migration CLI

## Tasks

1. Define interface; adapt existing JSONL `Store`.
2. Implement SQLite backend + tests (round-trip meta/messages/run_end; ListIDs).
3. Wire agent Create/Resume/List/Get to selected backend.
4. Document choice in design + README snippet.

## Acceptance

- [x] With Store=sqlite, Create + Send + Resume + List/Get work in tests.
- [x] Default remains JSONL with no behavior change for existing callers.

## Depends-on

- Milestone 0.5 List/Get
