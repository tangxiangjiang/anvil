# Phase p_0.6.5 — First-party CLI

**Status:** done

## Goals

Ship `anvil` CLI for local smoke and operator use, streaming progress from p_0.6.1.

## Scope

- Package `source/cmd/anvil` with subcommands: `prompt`, `chat` (interactive + `--resume`), `list`, `get`
- Env: `ANVIL_API_KEY`, `ANVIL_BASE_URL`, `ANVIL_MODEL`, `ANVIL_PROVIDER`, `ANVIL_MAX_STEPS`
- Optional read-only `.anvil/config` JSON in cwd for model/baseURL/provider/max_steps (no secrets required in file; API key still env-preferred)
- Stream assistant, tool_call, tool_result, progress; exit codes per design 07 (1 startup, 2 run error, 0 ok)
- Flags for store backend and MCP when available
- Keep `examples/oneshot` and `examples/interactive`; README points to CLI as primary
- Root README CLI quick start

## Non-goals

- TUI dashboard
- Cloud control plane

## Tasks

1. Scaffold cmd with flag/env parsing.
2. Implement prompt / chat / list / get.
3. Print progress events.
4. README + build note (`go build -o bin/anvil ./cmd/anvil`).

## Acceptance

- [x] `go run ./cmd/anvil list` works against a temp cwd with store files (no network).
- [x] `prompt` streams events and exits with correct codes on mock or documented live use.
- [x] README documents CLI.

## Depends-on

- p_0.6.1
- p_0.6.3 / p_0.6.4 flags optional if those phases done first (this phase ships after them in the milestone order)
