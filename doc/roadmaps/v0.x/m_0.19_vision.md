# Milestone 0.19 — Vision (image / screenshot)

**Status:** done  
**Product version:** 0.19.x

## Goals

Multimodal attachments on Send/Prompt and optional `read_image`, mapped to OpenAI-compatible and Anthropic image parts, with size limits and sandbox.

## Overall acceptance

1. Prompt with local png attachment reaches completer as image part (fake completer asserts).
2. Oversized image is downscaled or rejected with clear error.
3. Path outside cwd denied.
4. Vision disabled → no image parts / tool absent.

## Non-goals

- OS screenshot capture API
- Video
- Remote URL fetch by default

## Depends-on

- 0.4+ streaming completers; prefer 0.12 catalog `anvil.vision`
