# p_0.48.2 — The harness: three tiers, a digest, a scorer

**Status:** planned
**Milestone:** [m_0.48_evaluation_and_audit.md](../m_0.48_evaluation_and_audit.md)
**Linked design:** [45-evaluation.md](../../../design/v1.0/45-evaluation.md) §4, §5

## Goals

Turn `source/eval` from six scripted fixtures into a harness that can measure a change to the
request, the prompt or the agent tree: a scripted tier that can assert on the request it
answers, a recorded tier that replays real provider answers by request digest through the
public `Agent`, a live tier that produces those recordings, and one scorer that gives every
task the same numbers.

## Scope

`source/eval/` (the package: `task.go`, `script.go`, `replay.go`, `live.go`, `digest.go`,
`score.go`, `recordings/*.jsonl`, `eval_test.go`), `scripts/eval.sh` is **not** in this phase
(p_0.48.3). No change outside `source/eval`.

## Tasks

1. **`Task` gains a tier.** `Script []Reply` (tier 1) or `Recording string` (tier 2); `Live`
   is a flag on the run, not on the task. A `Reply` is today's `llm.Message` plus an optional
   `Expect func(llm.Request) error`.
2. **The scripted completer checks `Expect`.** A reply whose predicate fails fails the task
   with the predicate's error and the request it saw. Replies without one behave exactly as
   today.
3. **`RequestDigest`.** SHA-256 over `llm.Request` with the volatile fields removed: model id,
   the `cwd` line of the system prompt, the session-notes timestamp, temp-directory names in
   tool results. The list is one function with a test for each removed field.
4. **The replay completer.** Loads `recordings/<name>.jsonl`; answers by digest; a miss fails
   the task and prints a unified diff of the request against the nearest recorded one (by
   message count, then by digest prefix).
5. **The recorder.** With `ANVIL_EVAL_LIVE=1`, wraps the real completer, redacts the
   `Authorization` header, and writes one line per call next to the committed recording as
   `<name>.live.jsonl`. It never overwrites the committed file.
6. **Tier 2 runs through `anvil.Create` + `Send`**, with `Options.completer` set to the replay
   completer, so subagents, workflows, checkpoints and the permission callback are on the path.
7. **The scorer.** `Score{Completed, Steps, ToolErrors, Refused, LoopStops, Retries,
   RequestBytes, Agents}`, filled from the run's events and `Result`. `Retries` is recorded as zero
   until 0.49 adds retries; `Agents` is recorded as zero until 0.51 adds `delegate` and Complex.
8. **Move the six fixtures** onto the new `Task`; add `Expect` to `sandbox_escape_denied`
   (the system prompt carries the sandbox clause) and to `edit_file_unique` (the request's
   tool list includes `edit_file`).
9. **Record the first five.** Tier-2 tasks for: a two-file edit with a test run; a
   `spawn_agent` that reads and reports; a two-step `run_workflow`; a permission deny with
   no callback; a run that the loop guard stops. Recorded once against a real provider, then
   committed.
10. **Verify.** The eval package and the full Go suite from Git Bash.

### Gate

- 命令：`cd source && go test -count=1 ./eval/... -run 'TestFixtures|TestReplay|TestDigest'`
- 通过条件：六个脚本 fixture 通过；五个录制 fixture 通过；`TestDigest` 证明对模型 id、cwd、时间戳、临时目录名各改一次后 digest 不变，对 system prompt 加一句话后 digest 改变；`TestReplayMissIsADiff` 证明一个未命中的请求使任务失败且输出包含 `---`/`+++` 行。
- 失败条件：任一录制 fixture 因 digest 未命中而失败（说明 harness 自身改变了请求）；或 `TestDigest` 的任一变更方向判错；或任一任务 panic。
- 基线条目：每个任务的 `Score` 全部字段（此阶段先打印，p_0.48.3 写入文件）；`recordings/` 下每个文件的行数。

## Acceptance

- [ ] Tier 1 `Expect` fails a task with the request it saw.
- [ ] `RequestDigest` is stable across the volatile fields and sensitive to a prompt change.
- [ ] A digest miss fails the task with a diff.
- [ ] Recordings carry no `Authorization` value.
- [ ] Tier 2 tasks run through the public `Agent`.
- [ ] Every task prints one `Score`.
- [ ] `cd source && go build ./... && go vet ./... && go test -count=1 ./...` is green (run
      from Git Bash).

## Non-goals

- A baseline file or a compare rule (p_0.48.3).
- A tokenizer; `RequestBytes` is bytes.
- Fixtures for MCP servers, LSP, web search, or git remotes.
