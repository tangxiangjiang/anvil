# Milestone 0.61 — Design, roadmap, planning, and policy

**Status:** planned

Turn an approved requirement into an approved dependency-ready work item entirely in VS Code,
without starting execution. Design:
[61](../../design/v0.x/61-planning-and-policy.vscode.md).

## Goals

1. Bind Requirement, Design, Milestone, Phase, Plan, and Work-item revisions in one graph.
2. Make acceptance, budgets, runtime/tool/secret/network, delivery, and rollback policy explicit.
3. Move design, roadmap, gate, and plan authoring/approval out of Web.

## Overall acceptance

- VS Code produces an approved dependency-ready work item from an approved requirement.
- Cycles, stale revisions, missing acceptance, and unsupported capabilities fail before approval.
- Upstream changes invalidate downstream approvals through a visible impact diff.
- Passive planning actions start no Worker or external mutation.
- Web planning history is read-only audit.

## Non-goals

- Verification, review, publication, or release (0.63–0.65).
