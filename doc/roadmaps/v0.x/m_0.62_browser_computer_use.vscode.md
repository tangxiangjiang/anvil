# Milestone 0.62 — Browser and computer use

**Status:** planned

Add a supervised browser runtime and a separately gated desktop tier with prompt-injection,
secret, origin, external-write, and evidence boundaries. Design:
[62](../../design/v0.x/62-browser-and-computer-use.vscode.md).

## Goals

1. Deliver read-only browser sessions with trustworthy observations and traces.
2. Add permission-graded browser interaction and explicit external-write confirmation.
3. Add an opt-in, window-confined desktop tier after browser safety gates pass.

## Overall acceptance

- Web content cannot alter permissions, origins, tools, or secret policy.
- Read mode cannot submit or perform external writes.
- Stale/ambiguous targets fail without action.
- External writes require an action-specific approval and before/after evidence.
- Credentials/cookies/protected fields stay outside model-visible data.
- Stop/crash/restart terminates or reconciles supervised processes.

## Non-goals

- CAPTCHA/anti-bot bypass, unrestricted JavaScript, unrestricted desktop control, or unattended
  financial/legal/destructive workflows.
