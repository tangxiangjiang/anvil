## Goals

1. **A long, real-LLM tour.** Natural prompts drive catalogues, MCP runtime connect, builtin
   tools, approvals, checkpoint, fork, cancel, and session admin against a live provider.
2. **Opt-in only.** Build tag `livesmoke` plus `ANVIL_LIVE_SMOKE=1` and credentials; incomplete
   gate skips (does not fail). Default push CI stays offline-only.
3. **Nightly / manual CI.** A separate workflow can run when repository secrets are set.

## Scope

`source/internal/editorhost/live_protocol_smoke_test.go`, milestone docs, and
`.github/workflows/live-protocol-smoke.yml`.

## Tasks

1. Gate: `//go:build livesmoke`, require `ANVIL_LIVE_SMOKE`, `ANVIL_API_KEY`, `ANVIL_MODEL`.
2. Scenarios in `TestLiveProtocolSmoke` as listed in the milestone.
3. Workflow: `workflow_dispatch` + nightly schedule; inject secrets; test skips if empty.

## Acceptance

- [x] Without the tag / env, `go test ./internal/editorhost/` does not compile or run the live test.
- [x] Offline `TestProtocolTour` still green.
- [x] Documented local command with `-timeout 40m`.

## How to run

```bash
cd source
export ANVIL_LIVE_SMOKE=1
export ANVIL_API_KEY=...
export ANVIL_MODEL=...
# optional: ANVIL_BASE_URL, ANVIL_PROVIDER
go test -tags=livesmoke ./internal/editorhost/ -run TestLiveProtocolSmoke -count=1 -timeout 40m -v
```

PowerShell: `$env:ANVIL_LIVE_SMOKE=1` (and the other vars), then the same `go test` line.
