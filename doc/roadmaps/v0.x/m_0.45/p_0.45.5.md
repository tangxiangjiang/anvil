# Phase p_0.45.5 — Module split (behaviour-neutral)

**Status:** done

## Goals

Give the front end a structure the later phases can land in. This phase changes **no behaviour**: it
moves code, extracts the duplicated helpers into one definition each, and keeps the global-object
contract that `app.js` mounts through.

## Scope

- `js/features/delivery.js` → a `delivery/` directory, one file per surface.
- Shared helpers extracted to `js/features/delivery/shared/` and used by every feature.
- `index.html`'s `<script>` list is the only wiring change.

## Non-goals

- Any behavioural fix. If a bug is found while moving, it is recorded and fixed in the phase that
  owns it, not silently here.
- Changing the `window.Features.<name> = { mount, unmount, onRoute }` contract.
- Introducing a bundler or a build step.

## Tasks

1. **`js/features/delivery/index.js`** — the shell only: `mount`, `unmount`, `render`, `parseRoute`,
   `onRoute`, `reload`, the route→view dispatch, and the `go*` navigation helpers.
2. **One file per surface** — `reqs.js` (workspace, worker home, milestone view, version detail),
   `designs.js` (list, detail, ADR panes, version cards, compose/approve/bootstrap),
   `roadmap.js` (major list, canvas, milestone control cards, gate and acceptance strips),
   `test.js` (queue, control card, cases, fail/buglist, campaign), `wizard.js` (the create wizard,
   filesystem picker, milestone config pane).
3. **`shared/`** — `esc.js`, `badge.js`, `lifecycle.js` (labels and lifecycle→status mapping),
   `modal.js` (`uiModal` / `showUiModal` / `closeUiModal` / focus handling),
   `action.js` (`withAction`, added by p_0.45.4), `list.js` (the recurring card/list DOM
   construction). `clusters.js` and `nodes.js` switch to the shared `esc` / `notice` rather than
   keeping their own copies.
4. **Keep the mounting contract.** Each surface file attaches its methods to the one
   `window.Features.delivery` object (a plain `Object.assign` at load time) so `app.js`,
   `onRoute` dispatch and the embed that expects `Features.delivery` are untouched.

## Acceptance

- [ ] No file under `js/features/delivery/` exceeds ~1 200 lines.
- [ ] `esc`, `badge`, `lifecycleLabel` and the notice helper are each defined exactly once and used
      by `clusters.js` / `nodes.js`.
- [ ] `index.html` script order updated; no reference to the old `delivery.js` remains.
- [ ] Manual smoke of all four surfaces plus the create wizard behaves identically to the previous
      phase — same routes, same actions, same output.
- [ ] `git diff` for this phase contains moves and extractions only (reviewable as such).
