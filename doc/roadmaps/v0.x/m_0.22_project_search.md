# Milestone 0.22 — Project search engine (SQLite + VDB)

**Status:** done  
**Product version:** 0.22.x

## Goals

Ship a **local project search engine** backed by **SQLite (FTS5 + metadata) + embedded vectors**, implementing [13](../../design/v0.x/13-retrieval.md) storage concretely and powering `semantic_search`.

## Overall acceptance

1. `search.db` holds files/chunks; FTS query returns fixture hits without embeddings.
2. With embed endpoint (fake OK), hybrid search returns ranked chunks.
3. Re-build after one file change re-embeds only that file’s chunks.
4. `semantic_search` tool uses the engine; grep still works independently.

## Non-goals

- Remote Milvus/Qdrant required
- Multi-repo index
- jsonl index as primary (legacy sketch retired)

## Depends-on

- Design 13 tool contract; 0.12 gateway embed optional
- Existing sqlite driver patterns from store
