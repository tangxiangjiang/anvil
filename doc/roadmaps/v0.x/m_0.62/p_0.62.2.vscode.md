# p_0.62.2 — Sandbox policy, lifecycle, and recovery

**Status:** planned

## Goals

Run the owned Worktree under a fail-closed runtime-neutral sandbox contract.

## Scope

- Add capability/spec/instance schemas with immutable image and policy digests.
- Implement tested Docker/Podman/rootless adapters and unavailable-capability reporting.
- Enforce canonical mounts, non-root/capability/device policy, resources, output, time, and processes.
- Add default-deny network profiles and opaque process-scoped secret injection/redaction.
- Add signed ownership, cancellation, orphan reconciliation, workspace-only checkpoints, and
  idempotent cleanup.

## Tasks

1. Implement runtime capability/spec/instance and policy-digest contracts.
2. Add tested local container adapters, enforcement, lifecycle, secrets, and recovery.
3. Run adversarial escape/resource/network/secret/cancel/orphan fixtures.

## Acceptance

- Escape, host/sibling reads, runtime socket, secret, network, resource, timeout, and fork-bomb
  fixtures fail closed.
- Unsupported limits never fall back to weaker advertised isolation.
- Cancellation/restart yields one durable terminal or recovery state.
- Checkpoints/caches/layers/logs contain no secrets or host metadata.

## Non-goals

- Remote scheduling or whole-container snapshots.

## Depends-on

- p_0.62.1.
