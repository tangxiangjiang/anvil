# p_0.62.2 — Browser interaction, permissions, and trace

**Status:** planned
**Milestone:** [m_0.62_browser_computer_use.vscode.md](../m_0.62_browser_computer_use.vscode.md)
**Linked design:** [62-browser-and-computer-use.vscode.md](../../../design/v0.x/62-browser-and-computer-use.vscode.md)

## Goals

Add target-bound interaction while preserving explicit external-write and secret boundaries.

## Scope

Element fingerprints, click/type/select/scroll, uploads/download quarantine, permission ladder,
opaque secret typing, user takeover, approvals, before/after evidence, and accessibility.

## Tasks

1. Resolve model selector hints to current role/name/bounds/attribute fingerprints.
2. Refuse stale, hidden, ambiguous, cross-origin, or policy-blocked targets.
3. Classify external effects and require fresh native approval.
4. Add opaque secret handles and user takeover without model-visible values.
5. Render actions/traces and prove cancellation sends no interaction.

## Acceptance

- Every action is bound to the current observed target and policy level.
- External writes cannot inherit broad workspace permission.
- Secrets, cookies, authorization headers, and protected fields never reach transcripts/traces.
- Downloads stay quarantined; uploads name the exact approved file and origin.

## Non-goals

- Desktop interaction, CAPTCHA bypass, or unattended high-impact workflows.
