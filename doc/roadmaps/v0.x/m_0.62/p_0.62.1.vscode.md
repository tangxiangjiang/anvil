# p_0.62.1 — Supervised read-only browser runtime

**Status:** planned
**Milestone:** [m_0.62_browser_computer_use.vscode.md](../m_0.62_browser_computer_use.vscode.md)
**Linked design:** [62-browser-and-computer-use.vscode.md](../../../design/v0.x/62-browser-and-computer-use.vscode.md)

## Goals

Create a bounded browser process that can navigate approved origins and return trustworthy,
read-only observations.

## Scope

Runtime supervision, generated profiles, origin/network policy, tabs, DOM/accessibility tree,
screenshots, console/network summaries, durable evidence, stop/restart, and prompt-injection tests.

## Tasks

1. Define browser session/observation/action protocol and lifecycle.
2. Add host-owned Playwright/CDP adapter without arbitrary model JavaScript.
3. Enforce origin, tab, time, storage, download, CPU/memory, and output bounds.
4. Label page content untrusted and redact secrets/cookies/headers.
5. Add read-only Browser task view and trace documents.

## Acceptance

- Read-only sessions cannot click, type, submit, upload, or persist unsafe downloads.
- Disallowed origin and prompt-injection fixtures fail closed.
- Evidence is ordered, bounded, attributable, and restorable.
- Stop, process crash, and editor restart leave no uncontrolled browser.

## Non-goals

- Interaction, login automation, desktop control, or external writes.
