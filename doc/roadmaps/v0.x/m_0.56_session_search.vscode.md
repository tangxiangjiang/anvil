# Milestone 0.56 — Session search

**Status:** planned

Add one local query contract for JSONL and SQLite, a stable cursor protocol, and a VS Code
full-text Sessions experience. Search remains local by default, exposes no transcript content to
remote services, and must return equivalent observable results from both stores. The design is
chapter [56](../../design/v0.x/56-session-search-and-history.vscode.md).

## Goals

1. Define equivalent filtering, ordering, and full-text matching for JSONL and SQLite.
2. Page through a changing result set with an opaque, validated cursor protocol.
3. Provide responsive full-text search in the VS Code Sessions surface.
4. Increment the extension patch exactly once per user-visible delivery batch from the current
   package version; roadmap milestone 0.56 does not determine the plugin version.

## Ordering

p_0.56.1 defines store-equivalent result sets. p_0.56.2 adds transport-safe traversal over
those sets. p_0.56.3 consumes the query and cursor contracts without adding editor-only search
semantics.

## Overall acceptance

1. A shared corpus test runs every query case against JSONL and SQLite and compares ordered IDs,
   snippets, match metadata, and errors.
2. Pagination tests cover empty pages, invalid/expired cursors, concurrent inserts, deletion,
   deterministic ties, and no duplicate result within one traversal.
3. VS Code integration tests search content and metadata, load additional pages, cancel stale
   requests, open the selected session, and preserve local-only handling.
4. Tests assert no query or transcript body is sent through provider, telemetry, web, or MCP
   paths.
5. `cd source && go test -count=1 ./...` and `cd editors/vscode && npm test` pass; each visible
   delivery verifies the exact one-patch version bump and synchronized declarations.

## Non-goals

- Remote or cloud indexing, semantic/vector search, or sending transcript text to a model.
- Different feature sets or ordering between JSONL and SQLite.
- Cross-workspace global search or collaborative search indexes.
