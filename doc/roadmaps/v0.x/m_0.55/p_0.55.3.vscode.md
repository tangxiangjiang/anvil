# p_0.55.3 — Read-first workflow control center

**Status:** done
**Milestone:** [m_0.55_structured_plans.vscode.md](../m_0.55_structured_plans.vscode.md)
**Linked design:** [55-structured-plans-and-workflow-control.vscode.md](../../../design/v0.x/55-structured-plans-and-workflow-control.vscode.md)

## Goals

Give VS Code a control center that opens in a non-mutating inspection state and exposes explicit,
revision-safe plan approvals and dependency status.

## Scope

Plan list/detail projections, dependency visualization, evidence and status inspection,
approve/deny controls, stale-revision feedback, reconnect, accessibility, and empty/error states.

## Tasks

1. Load and display a plan without sending any mutation.
2. Show selected scope, prerequisites, blocked reasons, acceptance evidence, and revision.
3. Require explicit confirmation for approval/denial and send the displayed revision.
4. Refresh from authoritative state after commands and reconnect.
5. Bump the then-current VS Code extension patch exactly once before packaging this visible batch,
   synchronizing all required declarations.

## Acceptance

- `cd editors/vscode && npm test -- --runInBand` proves opening, expanding, filtering, and
  navigating a plan emit zero mutation RPCs.
- UI integration tests approve a subset only after explicit action, include the expected revision,
  display dependency blocks, and recover from a stale-revision response without retrying a
  mutation automatically.
- Reload/reconnect tests produce the same plan state from the durable host projection.
- `cd source && go test -count=1 ./... && cd ../editors/vscode && npm run package` plus packaged
  smoke tests pass after the exact one-patch bump.

## Non-goals

- Automatic reviewer UI, automatic approval, or re-plan controls.
- Free-form plan editing or drag-to-reorder dependencies.
- Making the editor the source of truth.
