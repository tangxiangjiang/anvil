# Milestone 0.64 — Autonomous review and reviewed delivery

**Status:** planned

Review verified changes under a read-only reviewer boundary, resolve selected findings through
bounded attempts, and deliver the exact reviewed commit through Git, PR, and CI. Design:
[64](../../design/v0.x/64-review-and-delivery.vscode.md).

## Goals

1. Add immutable review artifacts, evidence policy, read-only reviewer, and findings UX.
2. Add bounded repair, conflict proposal, and revision-safe re-planning.
3. Add exact-commit publication, PR lifecycle, durable CI, and Web delivery cutover.

## Overall acceptance

- Review verdicts are reproducible from immutable labelled evidence.
- Reviewer cannot write, publish, obtain credentials, or approve its own findings.
- Repair/re-plan is explicit, bounded, isolated, and freshly verified/reviewed.
- Only the exact reviewed commit reaches the approved remote/ref.
- PR/CI writes are previewed, idempotent, recoverable, and never automatic merge.
- Web review and delivery are read-only audit.

## Non-goals

- Automatic merge, release, or deployment (0.65).
- Trust-based review bypass or first-release multi-provider parity.
