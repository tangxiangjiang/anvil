# p_0.53.3 — Output ceiling and Continue generating UX

**Status:** done

## Goals

Let users choose a valid model-aware output ceiling and explicitly continue a length-truncated
answer as a new turn without automatically repeating tool calls.

## Scope

- Expose output ceiling controls constrained by the selected model's capability profile.
- Snapshot the effective ceiling with the turn and carry it through the host request path.
- Mark truncated answers clearly and offer Continue generating only for terminal truncation.
- Implement continuation as an explicit new user-authorized turn with context that asks for the
  remaining answer and forbids automatic replay of completed tool calls.
- Preserve ceiling and continuation provenance in replay.

## Tasks

- [x] Add validated output-ceiling state and model-change behavior.
- [x] Bridge the effective ceiling into the request contract.
- [x] Build truncation notice and accessible Continue generating action.
- [x] Add continuation safeguards, persistence, replay, and packaged tests.

## Acceptance

- [x] Extension tests reject values outside the selected profile's bounds and preserve a valid
  per-conversation value across reload.
- [x] Host/provider fixture tests prove the snapshotted ceiling reaches the request for that turn.
- [x] Continue generating appears after truncation but not after normal completion, cancellation,
  or provider failure.
- [x] Activating Continue generating creates one explicit new turn; fixtures prove completed tool
  calls are not automatically replayed and the user can cancel before sending.
- [x] Replay shows the original truncation and identifies the continuation turn that followed it.
- [x] Run `cd source && go test ./...` and `cd editors/vscode && npm test`; before this
  user-visible batch ships, increment the current `editors/vscode/package.json` patch exactly
  once, then package and run the packaged VSIX smoke test.

## Non-goals

- Automatic continuation or hidden extra provider calls.
- Guaranteeing that a model's continuation contains no repeated prose.
- Assigning the future patch number in this planned document.
