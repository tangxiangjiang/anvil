# Milestone 0.45 — Editor-host protocol smoke

**Status:** done (2026-10-20)
**Product version:** 0.45.x

0.35–0.44 grew the editor-host wire and the VS Code client. Coverage stayed fragmented: unit
tests, fake-host integration, a thin real-host handshake, and VSIX packaging smoke. This milestone
adds two acceptance paths: a cheap **offline** tour for every CI push, and an opt-in **live**
tour for long, real-LLM smoke (manual or nightly).

## Goals

1. **Offline tour (p_0.45.1).** One Go test drives initialize, catalogues, MCP listing (file
   only), session admin, and read/write/shell through the stub LLM — deterministic and free.
2. **Live tour (p_0.45.2).** A gated, long run against a real provider: MCP runtime connect,
   multi-turn tools, approvals, checkpoint, fork, cancel, session admin.
3. **CI by default stays offline.** Live smoke never blocks ordinary push/PR.
