# Phase p_0.11.2 - Local agentd listen & capacity

**Status:** done

## Goals

Run agentd as a local supervisor: IPC listen, auth handshake, capacity tracking, cwd allowlist -without full Anvil execution yet (may use stub worker).

## Scope

- Unix socket / Windows named pipe listen
- `hello` / `hello_ok` with token check
- `worker.list` reflecting slots (idle/busy/starting)
- Enforce max concurrent workers; document reject vs queue (pick one for 0.11)
- Resolve job repo/cwd **only** via allowlist id -path

## Non-goals

- Real LLM runs (stub assign OK)
- Cluster join

## Tasks

1. Implement IPC server + auth.
2. Worker slot registry and list RPC.
3. Allowlist resolution tests (reject unknown repo id / path escape).
4. Graceful shutdown drains or cancels in-flight stubs.

## Acceptance

- [x] Controller can hello + worker.list against a running agentd.
- [x] Assign to unknown cwd/repo id is rejected.
- [x] At max capacity, extra assign is rejected or queued per doc.

## Depends-on

- p_0.11.1
