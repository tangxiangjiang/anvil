# Phase p_0.11.1 - Protocol, config, skeleton

**Status:** done

## Goals

Lock the control protocol version, daemon/worker config shapes, and empty command packages so later phases only fill behavior.

## Scope

- Proto `1` message kinds: hello, worker.list, job.assign / event / cancel / done (names per design 11)
- Daemon config: listen path, auth token env, max workers, cwd allowlist entries
- Worker config: how agentd invokes worker binary; LLM env passthrough (`ANVIL_*`)
- `source/cmd/agentd` and `source/cmd/agent-worker` stubs; `internal/daemon` / `internal/worker` packages as needed
- Design 11 + architecture cross-links remain authoritative

## Non-goals

- Real assign/stream
- Cluster messages beyond type stubs

## Tasks

1. Write proto/schema doc or Go types for control messages.
2. Define YAML/flags for agentd allowlist + capacity.
3. Scaffold cmd packages with `--help` and version.
4. Unit tests for config validation (bad cwd, zero capacity).

## Acceptance

- [x] Proto/types compile and round-trip in tests.
- [x] agentd/agent-worker binaries build from `source/`.
- [x] Invalid config fails fast with clear errors.
