# p_0.63.3 — Desktop/manual evidence, repair handoff, and Web cutover

**Status:** planned

## Goals

Complete verification UX while keeping desktop interaction, repairs, and acceptance explicit.

## Scope

- Add opt-in selected-window/process desktop input, focus-loss cancel, emergency stop, and masking.
- Block protected applications/regions, terminals, password managers, security settings, and elevation.
- Add manual evidence attachment with actor/provenance and immutable campaign binding.
- Propose bounded approved repair items that return through 0.61/0.62 and require fresh verification.
- Remove Web test/fix/regression/browser/acceptance controls/routes; retain audit/export.
- Add platform, secret, injection, accessibility, reconnect, package, and smoke gates.

## Tasks

1. Implement confined desktop interaction, takeover safety, emergency stop, and masking.
2. Add manual evidence and bounded approved repair-item handoff.
3. Remove Web verification mutations and run platform/security/package gates.

## Acceptance

- Input cannot escape the selected current window/process.
- Unsupported platforms report unavailable capability without fallback.
- Failed verification starts no repair without approval and deterministic bounds.
- Web cannot run checks/actions/repairs or decide acceptance.

## Non-goals

- General remote desktop or autonomous review.

- p_0.63.1 and p_0.63.2.
