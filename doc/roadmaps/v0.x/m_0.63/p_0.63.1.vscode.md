# p_0.63.1 — Verification campaign and local evidence

**Status:** planned

## Goals

Bind approved acceptance criteria to durable attributable implementation evidence.

## Scope

- Add campaign/check/evidence schemas bound to artifact, execution, commit, environment, and policy.
- Run configured build/test/lint/type/LSP/project checks with bounded redacted output.
- Add acceptance-to-check coverage and passed/failed/blocked/inconclusive/cancelled outcomes.
- Persist sequence, duration, provenance, artifacts, truncation, and terminal manifest.
- Add VS Code campaign tree, logs/artifacts, selected/failed runs, stop, and manual-evidence request.

## Tasks

1. Implement campaign/check/evidence persistence, sequencing, and coverage.
2. Route configured local checks through bounded redacted durable runs.
3. Build VS Code campaign UX and reconnect/truncation/provenance tests.

## Acceptance

- Missing/stale/truncated/unsupported required evidence cannot pass.
- Every criterion maps to current evidence or explicit non-pass state.
- Reconnect restores identical campaign state; viewing starts no check.
- Outputs and artifacts obey size, provenance, authorization, and redaction policy.

## Non-goals

- Browser/desktop interaction, repair execution, or review.

- Milestone 0.62.
