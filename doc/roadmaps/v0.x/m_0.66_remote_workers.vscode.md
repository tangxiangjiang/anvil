# Milestone 0.66 — Remote Worker execution

**Status:** planned

Run approved structured work on authenticated remote Workers while preserving sandbox, durable
run, evidence, review, and publication boundaries. Design:
[66](../../design/v0.x/66-remote-workers.vscode.md).

## Goals

1. Define authenticated control-plane identity, enrollment, capabilities, policy, and scheduling.
2. Transport immutable source/result evidence and execute in remote 0.62 sandboxes.
3. Add durable queue/run/reconnect/cancel/retry UX and split-brain recovery gates.

## Overall acceptance

- Only authenticated, enrolled, lease-current, capability-matching Workers can execute.
- Source, environment, policy, and result digests verify end to end.
- Disconnect, duplicate messages, reassignment, and node loss never yield two accepted results.
- Secrets are workload-scoped and absent from logs/artifacts/model context.
- Remote results use 0.57 integration, 0.64 review/PR delivery, and 0.65 release gates.

## Non-goals

- Arbitrary SSH, shared mutable filesystem transport, live process migration, or trust-based review
  bypass.
