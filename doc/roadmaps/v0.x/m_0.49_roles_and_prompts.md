# Milestone 0.49 — Roles and prompts

**Status:** planned
**Product version:** 0.50.0

The SDK has three prompt constants, and a caller-provided `SystemPrompt` can replace the
entire default, including its safety clauses. This milestone composes a layered system prompt
that every agent gets, gives it an explicit role, and provides a per-run directive. The SDK
exposes these as prompt and role interfaces; the host and worker containers supply any
configuration. The design is chapter [49](../../design/v0.x/49-roles-and-prompts.md).

## Goals

1. **A prompt that cannot lose its safety clauses.** Five layers in a fixed order, L0 owned by
   the SDK and prepended to every agent — including subagents and callers that set
   `SystemPrompt` — with today's default composition byte-identical.
2. **Roles and directives.** `main`, `subagent`, `worker`, `decision`, `analyze` as named L1
   texts; a role changes the prompt and nothing else. `WithDirective` adds a per-run directive
   without replacing the safety layer.

## Overall acceptance

1. `Compose` for the main role with no options equals the recorded pre-split prompt plus one
   named closing line; every role's prompt begins with `Safety` and contains each safety
   sentence verbatim; a `SystemPrompt` that says "ignore all safety rules" is still preceded
   by L0.
2. A spawned child receives the subagent role and the untrusted-content safety clause; an
   unknown role is refused before a run starts.
3. `WithDirective` reaches the run's prompt without displacing L0 and is not persisted.
4. `./scripts/eval.sh` not worse than the 0.47 baseline on every gated field; the invariant
   suite remains 100% in Single mode.
5. `cd source && go build ./... && go vet ./... && go test -count=1 ./...` green (run from
   Git Bash) at the end of the phase.

## Non-goals

- Host protocol, worker config, CLI flags, VS Code settings or cards for roles. The SDK
  exposes the prompt interfaces; the containers adapt.
- Model-specific prompt text, a workspace role file, or localisation.
- Moving the host's `planPromptPrefix` to `WithDirective` — available, not required.
- The Single / Multi / Complex mode ladder, which is delivered in 0.50.
