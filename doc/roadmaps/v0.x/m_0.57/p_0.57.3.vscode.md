# p_0.57.3 — Merge/conflict review and cleanup

**Status:** done
**Milestone:** [m_0.57_worktree_workers.vscode.md](../m_0.57_worktree_workers.vscode.md)
**Linked design:** [57-worktree-workers.vscode.md](../../../design/v0.x/57-worktree-workers.vscode.md)

## Goals

Present attributed worker changes for explicit review, apply only a confirmed safe merge, expose
conflicts without destructive automation, and clean up only proven-owned resources.

## Scope

Diff/base validation, review state, merge preflight, confirmation, conflict representation,
abort/retry boundaries, post-merge verification, branch/worktree cleanup, reconnect, and audit.

## Tasks

1. Bind review to worker, worktree, base/head revisions, and current primary-tree state.
2. Require explicit confirmation after preflight; reject stale review or dirty target state.
3. Preserve conflict artifacts for review and provide safe abort without automatic resolution.
4. Clean only owned, non-needed resources after verified completion or explicit safe discard.
5. Before packaging this visible batch, bump the then-current extension patch exactly once and
   synchronize every required version declaration.

## Acceptance

- `cd source && go test -count=1 ./... -run 'TestWorktree(MergeReview|Conflict|Abort|FinalCleanup)'`.
- `cd editors/vscode && npm test -- --runInBand` proves no merge on open/preview, explicit
  confirmation, stale-base rejection, conflict display, safe abort, and blocked cleanup details.
- Dirty primary tree, changed base, mismatched attribution, failed preflight, and merge conflict
  all fail closed without deleting the worker worktree or branch.
- Successful-path fixtures verify the resulting commit/diff before owned-resource cleanup.
- Packaging and smoke tests pass after the exact one-patch bump; roadmap 0.57 is never used as the
  extension version.

## Non-goals

- Automatic merge, automatic conflict resolution, force push, or unreviewed branch deletion.
- Deleting work merely because the editor disconnected.
- Remote pull-request orchestration.
