# p_0.64.2 — Read-only reviewer Agent and findings UI

**Status:** planned
**Milestone:** [m_0.64_autonomous_review_replan.vscode.md](../m_0.64_autonomous_review_replan.vscode.md)
**Linked design:** [64-autonomous-review-and-replan.vscode.md](../../../design/v0.x/64-autonomous-review-and-replan.vscode.md)

## Goals

Run a role-separated reviewer and present its bounded evidence without granting mutation authority.

## Scope

Reviewer role/profile, read-only tools, prompt-injection boundary, context/evidence assembly,
finding validation, Workflow UI, source links, revisions, accept/dismiss decisions, accessibility.

## Tasks

1. Create a reviewer execution profile with immutable read-only permissions.
2. Build bounded context from reviewed artifacts rather than implementer prose.
3. Validate finding schema/evidence and persist reviewer/model identity.
4. Add grouped findings, source links, verdict, confidence, and revision comparison.
5. Prove view/refresh and finding decisions never mutate repository or lifecycle state.

## Acceptance

- Reviewer cannot write files, run lifecycle mutations, publish, or obtain credentials.
- Truncated/unsupported review displays incomplete evidence.
- Findings restore identically after reconnect.
- Dismiss/accept decisions are audited and do not edit files.

## Non-goals

- Repair attempts, re-plan, conflict application, merge, or PR approval.
