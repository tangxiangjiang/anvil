# p_0.64.1 — Review artifact and read-only reviewer

**Status:** planned

## Goals

Produce reproducible review findings from immutable implementation and verification evidence.

## Scope

- Add append-only review revisions, verdicts, finding ids/severity/locations, and evidence citations.
- Bind artifact, policy, Worker, commits/patch, acceptance, verification, model, and runtime evidence.
- Invalidate review on any bound revision/evidence change.
- Run a role-separated reviewer with immutable read-only permissions and no credentials.
- Add VS Code completeness, verdict, findings, stale/inconclusive state, and audited decisions.

## Tasks

1. Implement review/finding schemas, evidence bindings, invalidation, and audit.
2. Run the reviewer under immutable read-only capability and prompt-injection boundaries.
3. Build findings UX and reconnect/incomplete-evidence/security tests.

## Acceptance

- Missing/truncated/unsupported required evidence cannot pass.
- Reviewer cannot write, mutate lifecycle, publish, obtain credentials, or approve findings.
- Findings cite labelled evidence or are explicitly inconclusive.
- Reconnect restores the identical review revision and decisions.

## Non-goals

- Repair, re-plan, publication, or merge.
