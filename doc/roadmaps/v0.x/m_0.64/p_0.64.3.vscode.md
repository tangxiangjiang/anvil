# p_0.64.3 — Bounded repair, conflict proposal, and re-plan

**Status:** planned
**Milestone:** [m_0.64_autonomous_review_replan.vscode.md](../m_0.64_autonomous_review_replan.vscode.md)
**Linked design:** [64-autonomous-review-and-replan.vscode.md](../../../design/v0.x/64-autonomous-review-and-replan.vscode.md)

## Goals

Turn selected findings into controlled new work while preserving all human integration/publication
gates.

## Scope

Finding selection, repair item creation, attempt/time/token/scope bounds, fresh review, disposable
conflict proposal Worktree, structured plan diff, approval, stale handling, and loop audit.

## Tasks

1. Create repair items referencing immutable finding ids and original acceptance.
2. Enforce total attempts, elapsed time, tokens, and changed-scope limits.
3. Produce conflict resolution patches only in disposable owned Worktrees.
4. Produce a new proposed artifact revision with structured dependency/acceptance diff.
5. Require explicit decisions and add loop/stale/crash tests.

## Acceptance

- No repair/re-plan begins without an allowed durable decision.
- A proposal cannot mutate primary/original Worker or cancel running work.
- Each repair result receives a fresh independent review revision.
- Bounds stop recursion deterministically and preserve all attempts.

## Non-goals

- Automatic plan replacement, conflict application, integration, push, or unbounded fixing.
