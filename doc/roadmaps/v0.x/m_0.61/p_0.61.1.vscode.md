# p_0.61.1 — Remote identity, authentication, and publication

**Status:** planned
**Milestone:** [m_0.61_remote_git_pr_ci.vscode.md](../m_0.61_remote_git_pr_ci.vscode.md)
**Linked design:** [61-remote-git-pr-ci.vscode.md](../../../design/v0.x/61-remote-git-pr-ci.vscode.md)

## Goals

Define the provider-neutral remote boundary and publish only an exact reviewed commit.

## Scope

Repository discovery/configuration, GitHub adapter foundation, SecretStorage tokens, host allowlist,
short-lived Git credentials, remote/ref policy, drift checks, idempotency, and audit.

## Tasks

1. Define remote repository and delivery target wire/store schemas.
2. Add host-owned auth with scope diagnostics and complete redaction tests.
3. Resolve reviewed commit/refspec without model-supplied URLs or credentials.
4. Refuse force/non-fast-forward/protected updates and record partial outcomes.
5. Add fake-provider and real Git-remote fixtures.

## Acceptance

- Only the reviewed commit reaches the approved repository/head ref.
- Secrets are absent from prompts, logs, stores, environment, and Git config.
- Drift, missing scopes, SSO, protection, timeout, and unknown outcomes are recoverable/blocked.
- Repeating an operation cannot create a second publication.

## Non-goals

- Pull-request writes, CI, force push, or multi-provider parity.
