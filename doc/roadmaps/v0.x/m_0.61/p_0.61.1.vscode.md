# p_0.61.1 — Design and roadmap artifact graph

**Status:** planned

## Goals

Bind approved requirements to versioned designs, milestones, phases, and work items.

## Scope

- Define stable identities/revisions and exact Requirement → Design → Milestone → Phase → Work edges.
- Bind repository document paths, commits, digests, lifecycle state, and audit.
- Validate version naming, links, dependencies, cycles, and deterministic import/export.
- Mark downstream approvals stale when an upstream revision changes.
- Add compatibility mapping for existing Delivery and 0.55 artifact identities.

## Tasks

1. Implement graph schemas, revision edges, repository bindings, and audit.
2. Add version/link/dependency validation plus stale-impact calculation.
3. Add legacy mapping and deterministic import/export fixtures.

## Acceptance

- Cycles, broken links, duplicate ids, and document drift fail validation.
- A downstream node always resolves to exact approved upstream revisions.
- Supersession preserves old graph/audit and produces an impact set.
- Import/export round trips deterministically.

## Non-goals

- Execution policy, VS Code authoring UI, or running work.

## Depends-on

- Milestone 0.60 and delivered 0.55 artifacts.
