# p_0.61.3 — VS Code planning and Web cutover

**Status:** planned

## Goals

Make VS Code the sole design, roadmap, plan, gate, and approval client.

## Scope

- Add Design/Roadmap editors, outlines, dependency graph, work-item tree, validation, and audit.
- Add structured impact diff and explicit submit/approve/reject/supersede/re-open commands.
- Link Chat to exact planning revisions and diagnostics to fields/documents.
- Remove Web design/roadmap/gate/plan authoring and decision controls/routes.
- Keep read-only planning history/export and Open in VS Code.
- Add reconnect, stale, accessibility, real-service, package, and smoke gates.

## Tasks

1. Build Design/Roadmap editors, graph/tree projections, commands, and diagnostics.
2. Remove Web planning/decision controls while retaining audit/export/handoff.
3. Add stale/reconnect/accessibility/route/package/smoke coverage.

## Acceptance

- An approved requirement reaches an approved dependency-ready work item in VS Code.
- Live/restored planning state and decisions are identical.
- Passive planning actions perform no execution or provider write.
- Automated tests prove Web planning is audit-only.
