# p_0.61.3 — Durable CI observation and bounded repair loop

**Status:** planned
**Milestone:** [m_0.61_remote_git_pr_ci.vscode.md](../m_0.61_remote_git_pr_ci.vscode.md)
**Linked design:** [61-remote-git-pr-ci.vscode.md](../../../design/v0.x/61-remote-git-pr-ci.vscode.md)

## Goals

Observe required checks durably and convert failed evidence into an approved, bounded repair item.

## Scope

Webhook/subscription or bounded polling, check records, log/artifact retrieval, redaction, Workflow
status, rerun action, repair-item creation, attempt/time/token/scope limits, and release gates.

## Tasks

1. Journal check transitions with provider sequence/idempotency handling.
2. Retrieve bounded logs/artifacts with provenance and secret redaction.
3. Add explicit rerun and create-fix-attempt commands.
4. Route repairs through 0.60 and publication through 0.61.1/0.61.2.
5. Add outage, rate-limit, duplicate event, restart, and loop-bound tests.

## Acceptance

- CI state restores after restart without duplicate transitions.
- Viewing a failure never reruns CI or starts an Agent.
- Repair requires approval and cannot exceed configured bounds.
- Every published repair is a newly reviewed commit.

## Non-goals

- Infinite “fix until green”, automatic merge, or provider-specific workflow authoring.

## Depends-on

- p_0.61.1, p_0.61.2, and milestone 0.60.
