# Phase p_0.20.3 — Exec stdio plugin RPC

**Status:** done

## Goals

Supervise an external plugin binary; register remote tools; enforce permissions.

## Scope

- stdio JSON-RPC (or JSONL) handshake: manifest, list_tools, call_tool, shutdown
- Spawn with cwd + scrubbed env
- Crash → tool errors / job fail per policy
- Net denied unless permission granted (document; may simply not expose dial helper in MVP)

## Non-goals

- gRPC mandatory
- Marketplace install

## Tasks

1. Fake exec plugin fixture (small Go main).
2. Call tool round-trip test.
3. Kill plugin mid-call → bounded error.

## Acceptance

- [x] Exec sample tool callable from agent registry.
- [x] Plugin process reaped on Close.
