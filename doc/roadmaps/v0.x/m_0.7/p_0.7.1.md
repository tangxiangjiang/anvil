# Phase p_0.7.1 — Stable error codes

**Status:** done

## Goals

Make run failures classifiable beyond free-text `Err` strings (design 07 error table).

## Scope

- Public stable codes (e.g. `max_steps`, `cancelled`, `provider`, `tool_panic`) on `RunResult` and/or stream `error` events
- Keep existing string messages for humans; codes for machines
- Tests for MaxSteps and Cancel paths

## Non-goals

- HTTP status mapping catalog for every provider error

## Tasks

1. Define code enum/constants in public API.
2. Set codes in runtime loop + agent Wait mapping.
3. Document in design 07.
4. Unit tests + CLI optional print of code.

## Acceptance

- [x] MaxSteps failure has a documented stable code reachable from `RunResult`.
- [x] Cancelled run is distinguishable by code/status without parsing English text only.
