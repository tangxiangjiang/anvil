# Milestone 0.3 — Extensibility

**Status:** planned  
**Product version:** 0.3.x

## Goals

- Caller-registered custom tools on Options/Agent.
- MCP stdio (and optionally HTTP) servers merged into the tool registry.
- Permission hooks before mutating tools (write/edit/shell).
- Context compression for long sessions.

## Phase list

Phases will be added before implementation (e.g. `m_0.3/p_0.3.1.md` …). Placeholder intent:

1. Custom tool API  
2. MCP integration  
3. Permission hooks  
4. Context summarization  

## Overall acceptance

1. Custom tool appears in model tool list and executes.
2. At least one MCP stdio server tools are callable in an example.
3. Deny hook blocks a write without crashing the run.
4. Oversized history is summarized without losing Resume consistency.

## Non-goals

- Multi-agent orchestration / sub-agents
- Cloud
- Replacing the core Create/Send/Wait API
