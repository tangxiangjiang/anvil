# Milestone 0.24 — Scheduler as cluster controller + gateway catalog

**Status:** done  
**Product version:** 0.24.x

## Goals

In-tree scheduler: apps configure LLM over HTTP; agentd joins and receives api_key/base_url/model; jobs assigned by capacity; models listed from gateway.

## Overall acceptance

1. App `PUT /v1/llm` then agentd join → workers get base_url/api_key/model without local `ANVIL_*`.
2. Live `PUT /v1/llm` pushes `cluster.config` to joined nodes.
3. `GET /v1/models` matches gateway using configured credentials.
4. `POST /v1/jobs` completes via joined agentd; `GET /v1/nodes` shows capacity.
5. Cluster-disabled agentd unchanged; secrets never in logs.

## Non-goals

- Web admin, HA, event streaming, advanced autoscaler
