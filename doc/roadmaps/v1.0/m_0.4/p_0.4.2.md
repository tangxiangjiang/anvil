# Phase p_0.4.2 — Stronger edit tooling

**Status:** done

## Goals

Improve multi-file / multi-hunk edits without abandoning cwd sandbox.

## Scope

- `apply_patch` tool with Begin/End Patch format (Update / Add / Delete + `@@` hunks)
- Better `edit_file` errors (nearest context hint; uniqueness guidance)
- System prompt prefers `edit_file` vs `apply_patch` appropriately

## Patch format (locked)

```text
*** Begin Patch
*** Update File: path
@@
 context
-old
+new
*** Add File: path
+line
*** Delete File: path
*** End Patch
```

## Non-goals

- AST-aware refactors / LSP rename
- Binary file editing

## Tasks

1. Spec patch format in this phase.
2. Implement tool + tests.
3. Update system prompt tip sheet.

## Acceptance

- [x] Patch tool can apply a multi-hunk change in tests.
- [x] Failed edits return actionable errors to the model.
