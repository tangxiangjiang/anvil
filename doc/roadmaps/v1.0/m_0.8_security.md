# Milestone 0.8 — Security hardening (design 08)

**Status:** done  
**Product version:** 0.8.x  
**Design:** [08-security.md](../../design/v1.0/08-security.md)

## Goals

Close remaining controls from design 08 beyond the MVP sandbox (path confine, shell gate, output caps, no key in JSONL).

Permission callbacks already exist (0.3). File-based Cursor-style hooks stay in **0.10**. This milestone focuses on containment, redaction, and prompt-injection hardening inside Anvil itself.

## Overall acceptance

1. Symlink escape outside cwd is denied for file tools (tested).
2. Common secret patterns are redacted or omitted from streamed tool results / logs (documented policy).
3. Default system prompt strengthens untrusted-file guidance; optional deny-list patterns for exfil-style shell (best-effort, documented limits).

## Non-goals

- seccomp / containers / VM
- Shell network allowlist product (caller responsibility; may document patterns only)
- Full human approval UI (use Permission + 0.10 hooks)
