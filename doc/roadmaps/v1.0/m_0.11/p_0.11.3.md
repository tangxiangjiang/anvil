# Phase p_0.11.3 — agent-worker assign / stream / cancel

**Status:** planned

## Goals

Wire agent-worker to Anvil Local so a real job streams events and supports cancel.

## Scope

- agentd spawns or reuses agent-worker per slot
- `job.assign` → Anvil Create/Prompt (or Send) with allowlisted cwd
- Stream `job.event` from Anvil run events
- `job.cancel` → run cancel + grace then kill
- `job.done` terminal status
- Env: API key / base URL / model from daemon/worker env (no secrets in config files)

## Non-goals

- Cluster forward
- cloud-agent event schema adapter (optional note only)
- Parallel Runs on one worker

## Tasks

1. Worker entry: load job, call anvil, forward events to daemon.
2. Map Anvil stream → `job.event`; tests with fake completer or recorded fixtures.
3. Cancel path integration test.
4. Document operator smoke (local socket + one job).

## Acceptance

- [ ] End-to-end: assign → events → done against a fixture repo (LLM may be stubbed in CI).
- [ ] Cancel stops the run and frees the slot.
- [ ] API keys never appear in logs or IPC payloads beyond env on worker start.

## Depends-on

- p_0.11.2
- Anvil 0.10 local surface
