# Phase p_0.11.4 — Cluster edge (join / forward)

**Status:** planned

## Goals

Make agentd a **cluster edge**: join a coordinator, heartbeat capacity, forward inbound assigns onto the same local job path.

## Scope

- Config: cluster URL, node id, auth (env)
- `cluster.join` / heartbeat with advertised max/idle workers
- Inbound cluster assign → local `job.assign` path
- Report job done/error upstream
- If no test coordinator exists, ship a minimal loopback fake for tests

## Non-goals

- Writing a production scheduler / autoscaler
- Multi-hop routing between daemons
- Public unauthenticated cluster listen

## Tasks

1. Cluster client interface + config.
2. Heartbeat goroutine; reconnect backoff.
3. Forward assign integration test with fake scheduler.
4. Document that scheduler is external; agentd only edges.

## Acceptance

- [ ] With cluster enabled, daemon joins and heartbeats in tests.
- [ ] Cluster-originated assign runs on a local worker and reports completion.
- [ ] With cluster disabled, local-only behavior unchanged.

- p_0.11.3
