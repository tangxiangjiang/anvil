# p_0.44.4 — The host exposes the runtime

**Status:** planned
**Milestone:** [m_0.44_mcp_management.md](../m_0.44_mcp_management.md)
**Linked design:** [43-mcp-management.md](../../../design/v1.0/43-mcp-management.md) §4

## Goals

1. **Every session shares the host's runtime.** `buildOptions` attaches the runtime for the
   session's `(cwd, sources)`; a server that is down or a file that will not parse no longer
   refuses a session.
2. **`mcp.list` can be believed.** It returns the observed state, tool count and error beside
   the configuration, plus a `problem` when a file is malformed. It stays additive and marks
   itself with `runtime: true`.
3. **Management is one round trip.** Add, update, remove, enable/disable, reconnect, sign in and
   sign out each write/reload and return the fresh listing.
4. **Changes reach idle sessions now, running ones next turn.** State transitions are pushed as
   `mcp.status` notifications.

## Scope

`source/internal/editorhost/proto.go`, `server.go`, a new `source/internal/editorhost/mcp.go`,
`session.go`, and tests. The host may import only package `anvil`.

## Tasks

1. **Protocol.** Extend `MCPListParams` with `include_tools`; extend the result with `runtime`,
   per-server `enabled/state/tool_count/tools/error/connected_at/env_names/header_names`, and a
   `problem` object. Add methods `mcp.add`, `mcp.update`, `mcp.remove`, `mcp.set_enabled`,
   `mcp.reconnect`, `mcp.authenticate`, `mcp.sign_out` and the `mcp.status` notification.
   Capabilities gain `mcp.runtime`.
2. **Registry.** The host keeps `map[key]*anvil.MCPRuntime` with key `cwd + sorted(sources)`.
   Creation is lazy; the first session for a key calls `Reload` synchronously (bounded by the
   per-server connect timeout), while a panel asking before any session starts the connection in
   the background and returns `connecting` statuses. `closeAll` closes every runtime.
3. **buildOptions.** When at least one source is enabled, attach the runtime and do not pass
   file MCP through the ordinary path; with no sources the session stays inline-only.
4. **Handlers.** Every management call validates scope/source, delegates to the public
   `mcpconfig` writers, reloads the runtime, and refreshes idle sessions for that runtime.
   `mcp.list` reloads (a diff-only read of the files) so external edits are seen; a malformed
   file is a result with `problem`, not an RPC error.
5. **Notifications.** Runtime `OnChange` maps to `mcp.status` per affected server, carrying the
   same server object as the listing and the source set. A notification is sent for connecting,
   connected, failed and auth-required transitions.
6. **Sessions.** Record the source set and runtime key on `session`; `RefreshMCP` errors during a
   run are swallowed and retried by the next `Send`, which already refreshes.
7. **Tests.** Host tests with a temp workspace and an `httptest` Streamable HTTP server (no
   import of `internal/mcp`): session opens with a down server; listing states; add/remove/
   toggle landing in the selected file with unknown fields preserved; notification ordering;
   shutdown closes the runtime.

## Acceptance

- [ ] A workspace with one broken and one good server opens a session; the good tools are
      registered; `mcp.list` reports both states.
- [ ] A malformed file produces `problem` in the result and a read-only listing, not `-32000`.
- [ ] `mcp.add/update/remove/set_enabled` write the requested scope and return the fresh
      listing; an idle session's tools change immediately, a running one after its turn.
- [ ] `mcp.reconnect` restarts one server and reports the new state.
- [ ] `mcp.authenticate` returns a URL and the completion produces `mcp.status connected`.
- [ ] `independence_test.go` still passes; host shutdown closes every runtime.
- [ ] `cd source && go build ./... && go vet ./... && go test -count=1 ./...` green.

## Non-goals

- Reimplementing config editing in the host; it calls the public writers.
- Multiple concurrent runs per session, or applying config changes mid-run.
- Persisting runtime state across host restarts.
