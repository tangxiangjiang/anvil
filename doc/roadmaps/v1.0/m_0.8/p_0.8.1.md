# Phase p_0.8.1 — Symlink-safe path containment

**Status:** planned

## Goals

Honor design 08: containment check after symlink resolution where possible.

## Scope

- Resolve symlinks (or use `EvalSymlinks` / equivalent) before allowing file tool paths
- Reject targets outside cwd
- Tests: symlink pointing outside temp cwd is denied

## Non-goals

- TOCTOU-proof kernel sandbox

## Tasks

1. Audit `resolvePath` / join helpers in tools.
2. Apply to read/write/edit/patch/grep roots as applicable.
3. Tests on Windows + document Unix expectation.

## Acceptance

- [ ] Symlink escape denied with IsError tool result (or create-time path error).
- [ ] Normal in-cwd files still work.

## Depends-on

- Milestone 0.1 tools sandbox
