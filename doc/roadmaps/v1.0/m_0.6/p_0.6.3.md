# Phase p_0.6.3 — MCP HTTP/SSE transport

**Status:** done

## Goals

Support remote MCP servers over HTTP/SSE in addition to stdio.

## Scope

- Extend `MCPServerConfig` with `URL` and `Transport` (`stdio` | `sse` | `http`; empty + Command ⇒ stdio)
- `internal/mcp` client for SSE and/or streamable HTTP (prefer mcp-go or minimal compatible client)
- Stdio path unchanged
- Tests with httptest fake MCP (or in-process fake)
- Resume still requires re-passing MCP configs

## Non-goals

- OAuth / browser auth productization
- Changing tool naming / permission rules for MCP tools

## Tasks

1. Public config fields + validation (URL vs Command).
2. Implement remote session Start/Call/Close.
3. Wire Create/Resume registry merge.
4. Fake server test.

## Acceptance

- [x] At least one non-stdio transport can list a tool and execute it in tests.
- [x] Stdio MCP tests still pass.

## Depends-on

- Milestone 0.3 MCP stdio
