# Milestone 0.15 — Web search

**Status:** done  
**Product version:** 0.15.x

## Goals

Add opt-in **`web_search`** (and **`fetch_url`**) so agents can query the public web via a configured provider or MCP, with SSRF-safe fetch.

## Overall acceptance

1. With WebSearch enabled and a fake HTTP provider, `web_search` returns titled hits to the model.
2. Default (no config) does not register web tools / does not egress.
3. `fetch_url` blocks private IPs by default; allows a public httptest fixture.
4. `DisallowedTools` / group `web` can strip the tools.

## Non-goals

- In-house crawler / search index of the web
- Browser automation
- Mandatory model-gateway search route

## Depends-on

- 0.10 tool filters; prefer hooks deny by tool name (0.10/0.14)
