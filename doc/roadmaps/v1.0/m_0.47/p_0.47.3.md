# p_0.47.3 — Plan review

**Status:** planned (2026-10-20)
**Milestone:** [m_0.47_editor_polish.md](../m_0.47_editor_polish.md)
**Linked design:** [44-editor-polish.md](../../../design/v1.0/44-editor-polish.md) §5

## Goals

1. **The plan is a document.** A plan-mode answer opens in a read-only virtual document
   (`anvil-plan:`), separate from the scrolling transcript.
2. **Approval is explicit.** Approve switches back to the mode the session had before plan
   mode and sends one fixed instruction; reject stays in plan mode.
3. **Read-only means read-only.** Nothing in the document can execute, write, or post a
   message.

## Scope

New `editors/vscode/src/planDocument.ts`; `src/chatPanel.ts`, `src/extension.ts`,
`src/protocol.ts` (types only), `media/chat.js`, `media/chat.css`; tests; README.

## Tasks

1. **Provider.** `TextDocumentContentProvider` for `anvil-plan:`, registered on activate and
   disposed with the extension; content is the last assistant text of a plan-mode turn.
2. **Event.** `chatPanel` posts `plan` with the text and the run id when a plan-mode turn
   ends; the card offers "Open plan", "Approve and run", "Keep planning".
3. **Approve.** Remember the pre-plan mode, `applyOptions({permission_mode})`, then `prompt`
   a fixed sentence. Reject returns focus to the composer without sending anything.
4. **Commands.** `anvil.openPlan`, `anvil.approvePlan`, `anvil.rejectPlan` contributed and
   registered.
5. **Safety.** The document scheme is read-only (`FileSystemProvider` not registered; the
   document is content-only), rendering is `textContent`, and no command is reachable from
   the document text.
6. **Tests.** plan mode still withholds write tools; approve happens before any write; the
   provider is disposed with the panel; wire params pinned.

## Acceptance

- [ ] A plan-mode answer opens as a document with the same text as the transcript.
- [ ] No write tool is callable before approval (existing plan-mode test unchanged).
- [ ] Approve returns to the stored mode; reject leaves the mode as plan.
- [ ] Closing the window leaves no registered provider or stale document.
- [ ] `npm test` green.

## Non-goals

- A structured plan object, step checklists, or per-file plan diffs.
- A plan queue across sessions.
- Editing the plan in the document.
