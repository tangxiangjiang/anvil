## Decisions (before any change)

- **The product version and the protocol revision are two variables, deliberately.**
  `editorhost.Version` is the build the extension compares against the release line it
  packaged (dotted minor); `ProtocolVersion` stays **1** because every 0.47 addition is an
  optional field or method an older peer ignores. Raising the protocol number would make a
  0.47 client refuse an 0.44 host it can talk to.
- **The lock file follows the manifest; it is not a second place to edit.** Both were moved to
  0.47.0 together, and `npm ci` is what keeps them from drifting.
- **Corrections are annotations, never rewrites.** A sentence that 0.47 overturns gets a
  parenthetical or a note naming the chapter that supersedes it; the original stays so a
  reader can see what was believed before.
- **The cutoff is stated as a range.** The index pages say "through 0.47" rather than listing
  a version in three places that would then have to be kept in step.
