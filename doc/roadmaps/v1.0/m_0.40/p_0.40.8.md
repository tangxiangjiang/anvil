# p_0.40.8 — Usage on the stream, and a context meter

**Status:** planned
**Milestone:** [m_0.40_editor_alignment.md](../m_0.40_editor_alignment.md)
**Linked design:** [39-editor-alignment.md](../../../design/v1.0/39-editor-alignment.md), [07-streaming-and-errors.md](../../../design/v1.0/07-streaming-and-errors.md)

## Goals

1. **A client learns token usage during the run, not only after it.** The terminal event carries the
   run's `Usage`.
2. **The meter is honest.** A percentage needs a context window; nothing in the catalog defines
   one, so it comes from a setting and is absent when unset.

## Scope

`source/types.go` (the event), `source/agent.go` (emission), `source/internal/editorhost/server.go`
(forwarding), `editors/vscode/src/` (protocol, panel), `media/chat.js` (composer meter), tests.

## Tasks

1. **The event.** `anvil.Event` gains `Usage *Usage`, set on the terminal event of a step/run. A
   consumer that ignores it is unaffected.
2. **The host.** Forward `usage` in the event payload when present; omit otherwise, so an old
   client sees the same shape.
3. **The setting.** `anvil.contextWindow` (number, default 0 = unknown).
4. **The client.** The composer shows cumulative input and output tokens for the session; when
   `contextWindow > 0` it also shows the last run's total as a fraction of it. No per-model table,
   no guessed window.
5. Tests and docs.

## Acceptance

- [ ] A completed run's terminal event carries non-zero usage, and the host payload includes it.
- [ ] A client that ignores the field (the existing tests) is unaffected.
- [ ] With `contextWindow` unset the meter shows counts only; with it set the fraction is shown.
- [ ] The meter survives the session (cumulative) and resets for a new session.
- [ ] `go test ./...` green; `npm test` green.

## Non-goals

- A per-model context-window table, or reading one from a provider response.
- A cost estimate in currency.
- Usage for a replayed transcript (the store's `run_end` usage already covers what it has).

## Depends-on

- p_0.7 (the event stream), p_0.38.3 (the panel's run boundaries)
