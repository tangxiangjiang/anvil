# p_0.40.7 — Web search and fetch

**Status:** planned
**Milestone:** [m_0.40_editor_alignment.md](../m_0.40_editor_alignment.md)
**Linked design:** [39-editor-alignment.md](../../../design/v1.0/39-editor-alignment.md), [15-web-search.md](../../../design/v1.0/15-web-search.md), [08-security.md](../../../design/v1.0/08-security.md)

## Goals

1. **The tools 0.15 built are reachable from the extension.** A setting turns them on and configures
   the provider.
2. **The key follows the model key's discipline.** SecretStorage only; injected as
   `ANVIL_WEB_SEARCH_API_KEY`; never in settings, logs or the protocol.
3. **Off means absent.** When disabled, the tools are not registered at all.

## Scope

`editors/vscode/package.json`, `editors/vscode/src/settings.ts`, `editors/vscode/src/extension.ts`
(two key commands), `source/internal/editorhost/` (`buildOptions`), the panel status row, tests.

## Tasks

1. **Settings.** `anvil.webSearch.enabled` (default false), `anvil.webSearch.provider`
   (`http` | `mcp`), `anvil.webSearch.baseUrl`, `anvil.webSearch.maxResults`.
2. **The key.** Commands `anvil.setWebSearchKey` and `anvil.clearWebSearchKey`, mirroring the
   model-key commands; the value goes to SecretStorage and from there into the child environment
   as `ANVIL_WEB_SEARCH_API_KEY`.
3. **The host.** `buildOptions` sets `Options.WebSearch{Enabled, Provider, BaseURL, APIKeyEnv:
   "ANVIL_WEB_SEARCH_API_KEY", MaxResults}`. `AllowPrivateURLs` stays false.
4. **The panel.** When enabled, a compact row says web tools are on and whether a key is present;
   when disabled the row is absent. The `web` permission group gates the calls.
5. Tests and docs.

## Acceptance

- [ ] Enabled with a provider and key: the host options carry `WebSearch.Enabled` and the env var
  name; the tool list a session can call includes the web tools.
- [ ] Disabled: no `WebSearch` option is set and the tools are absent.
- [ ] The key is never present in settings JSON, the log, or a protocol payload — asserted by a
  test that greps what the fake host received.
- [ ] The panel row appears only when enabled.
- [ ] `go test ./...` green; `npm test` green.

## Non-goals

- A built-in search backend or a proxy.
- Relaxing `AllowPrivateURLs`, or a per-URL allowlist UI.
- Caching results across runs.

## Depends-on

- p_0.15 (the tools), p_0.35.2 (`buildOptions`), p_0.36.3 (the `web` group)
