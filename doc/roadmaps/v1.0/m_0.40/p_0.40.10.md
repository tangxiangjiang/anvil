# p_0.40.10 — Input and panel affordances

**Status:** planned
**Milestone:** [m_0.40_editor_alignment.md](../m_0.40_editor_alignment.md)
**Linked design:** [39-editor-alignment.md](../../../design/v1.0/39-editor-alignment.md), [35-vscode-extension.md](../../../design/v1.0/35-vscode-extension.md)

## Goals

1. **Escape interrupts.** The composer cancels the running turn; the Stop button stays.
2. **Files can be dropped and images chosen.** A drop becomes mention chips or image attachments;
   a picker offers what paste already accepts.
3. **Prompts can be recalled.** Up and Down walk the prompts already sent in this session.
4. **An answer can be copied, and the run's state is visible from anywhere.** A copy action on
   assistant messages and a status-bar item that opens the chat.

## Scope

`editors/vscode/media/chat.js`, `media/chat.css`, `src/chatPanel.ts`, `src/extension.ts`,
`package.json`, tests.

## Tasks

1. **Escape.** A keydown on the composer cancels when a run is active, and does nothing otherwise —
   it must not dismiss a palette or clear the draft.
2. **Drag and drop.** Dropping files on the panel adds text files as mentions and image files as
   attachments, reusing the existing caps and the existing message types.
3. **Image picker.** A button next to the attach button opens a file dialog filtered to images and
   posts the same `{data, mime}` attachment shape paste produces.
4. **History.** Up/Down at the start/end of the input walks the prompts sent this session; a draft
   being edited is preserved when the walk returns to the bottom.
5. **Copy.** Each assistant message gets a copy action using the clipboard API; no `innerHTML`.
6. **Status bar.** One item per window: idle, running, waiting for approval; click opens or focuses
   the chat tab. It is updated from the same state the tab uses, so it cannot disagree.
7. Tests and docs.

## Acceptance

- [ ] Escape during a run sends `cancel`; Escape with nothing running leaves the draft intact.
- [ ] Dropping a `.ts` file adds a mention; dropping a `.png` adds an image attachment.
- [ ] The picker produces exactly the same attachment shape as paste.
- [ ] Up/Down recall prompts in order and restore the draft when returning to the bottom.
- [ ] Copy places the message text on the clipboard.
- [ ] The status bar reflects idle / running / waiting and opens the chat on click.
- [ ] `npm test` green.

## Non-goals

- Multi-line editing chords, Vim bindings, or a rich-text composer.
- Global (cross-session) prompt history on disk.
- Dragging text selections into the panel.
- A status-bar item per tab.

## Depends-on

- p_0.35.4 (the composer and renderers), p_0.40.1 (the per-tab state the status bar mirrors)
