# Milestone 0.5 — Operator surface

**Status:** done  
**Product version:** 0.5.x

## Goals

Make Anvil operable in CI and long-running hosts: list/inspect agents, clearer usage, and a minimal eval harness.

## Overall acceptance

1. List agents for a cwd without opening each JSONL manually.
2. Callers can read cumulative token usage for a run/agent when providers return usage.
3. At least one scripted eval task runs offline with a mock Completer.

## Non-goals

- Hosted dashboard / cloud control plane
- Billing integration
