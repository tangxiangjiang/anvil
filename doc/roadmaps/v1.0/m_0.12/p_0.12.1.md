# Phase p_0.12.1 -  Gateway config, auth, catalog

**Status:** done

## Goals

Runnable gateway skeleton: load route/catalog config, authenticate clients, serve `GET /v1/models`.

## Scope

- YAML/JSON config: listen addr, client tokens, model → upstream map
- Bearer auth middleware
- `GET /v1/models` OpenAI-shaped list (+ optional `anvil` extension fields)
- `cmd/anvil-gateway` (or agreed path) builds from `source/`

## Non-goals

- Chat proxy
- TLS termination (document reverse-proxy)

## Tasks

1. Config types + validation tests.
2. Auth reject/accept tests.
3. Catalog handler tests with fixture config.

## Acceptance

- [x] Invalid token → 401; valid → 200 models list matching config ids.
