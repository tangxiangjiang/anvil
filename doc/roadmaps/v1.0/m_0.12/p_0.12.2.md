# Phase p_0.12.2 -  Chat completions proxy

**Status:** done

## Goals

Proxy `POST /v1/chat/completions` (stream + non-stream) to the upstream selected by `model`.

## Scope

- Resolve model id → upstream base URL + upstream model name + API key env
- Forward tools/messages enough for Anvil OpenAI adapter
- Stream SSE passthrough
- Unknown model → 4xx

## Non-goals

- Full Anthropic Messages proxy (optional follow-up)
- Retry storm / complex load balancing

## Tasks

1. Proxy handler + upstream client.
2. Integration test with httptest fake upstream.
3. Redaction of upstream key in logs.

## Acceptance

- [x] Streamed completion returns tokens from fake upstream through gateway.
- [x] Wrong model id does not hit default upstream silently (unless `default_model` set).

## Depends-on

- p_0.12.1
