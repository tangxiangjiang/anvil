# Milestone 0.21 — Development memory (plugin)

**Status:** planned  
**Product version:** 0.21.x

## Goals

Ship first-party **`memory` plugin** with write/read/search over a cwd-local store. Depends on plugin Host (0.20). Session Resume remains core and unchanged.

## Phase list

| Phase | File | Status | Delivery |
|-------|------|--------|----------|
| p_0.21.1 | [m_0.21/p_0.21.1.md](m_0.21/p_0.21.1.md) | planned | Store + entry schema + memory_write/read/list |
| p_0.21.2 | [m_0.21/p_0.21.2.md](m_0.21/p_0.21.2.md) | planned | memory_search (lexical; optional embed) |
| p_0.21.3 | [m_0.21/p_0.21.3.md](m_0.21/p_0.21.3.md) | planned | Plugin pack wiring, sessionStart hint, docs |

## Overall acceptance

1. With `Plugins: ["memory"]`, agent can write and search an entry across Resume of a **new** agent id on same cwd.
2. Without the plugin, memory tools are absent; core Resume still works.
3. Entries stay under `.anvil/memory/`; path sandbox held.
4. Secret-like strings redacted or rejected on write (best-effort).

## Non-goals

- Builtin core memory tools
- Cloud sync
- Auto-memorize every message

## Depends-on

- Milestone 0.20 plugin Host (in-tree path sufficient)
- Prefer 0.13 embed only if vector search claimed
