# Milestone 0.9 — Extensibility depth (design 09)

**Status:** planned  
**Product version:** 0.9.x  
**Design:** [09-extensibility.md](../../design/v1.0/09-extensibility.md)

## Goals

Deepen design 09 beyond what 0.3 (custom tools / MCP stdio / Permission / compression) and 0.6 (MCP HTTP/SSE) already shipped—without pulling **0.10 SDK parity** items (`settingSources`, file hooks, SystemPrompt public knobs).

## Phase list

| Phase | File | Status | Delivery |
|-------|------|--------|----------|
| p_0.9.1 | [m_0.9/p_0.9.1.md](m_0.9/p_0.9.1.md) | planned | Compression quality + Resume summary markers |
| p_0.9.2 | [m_0.9/p_0.9.2.md](m_0.9/p_0.9.2.md) | planned | Parallel tool execution (optional opt-in) |
| p_0.9.3 | [m_0.9/p_0.9.3.md](m_0.9/p_0.9.3.md) | planned | MCP headers + richer server options (non-OAuth) |

## Overall acceptance

1. Compression leaves durable markers so Resume does not blindly explode history again.
2. Opt-in parallel tool calls complete a multi-call assistant step faster without breaking sequential default.
3. HTTP MCP configs can attach static headers; stdio unchanged.

## Non-goals

- Sub-agents (still deferred; needs explicit redesign — not this milestone)
- Cursor `settingSources` / hooks.json (→ **0.10**)
- Breaking Create/Send/Wait
