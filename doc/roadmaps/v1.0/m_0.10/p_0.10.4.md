# Phase p_0.10.4 — Hooks minimal + optional prewarm

**Status:** planned

## Goals

File-based policy hooks (Cursor-style project boundary) and optional workspace prewarm for hosts.

## Scope

- Load `.cursor/hooks.json` (and/or `.anvil/hooks.json`) when `settingSources` includes project — minimal command hooks for before shell (optionally write/edit)
- Hook deny → tool error to the model (do not crash process)
- Optional `Prewarm(cwd, sources)` that resolves rules/MCP/ignore once for faster first Send
- Document unsupported Cursor hook events as deferred

## Non-goals

- Full Cursor hooks event catalog
- Enterprise/team hook layers
- GUI approval prompts

## Tasks

1. Define minimal hook schema subset.
2. Wire shell (mutating) path through hook runner.
3. Prewarm helper + test.
4. Design 08/09/10 notes.

## Acceptance

- [ ] Fixture hooks.json can deny a shell command; agent run continues with tool error.
- [ ] Prewarm returns a release/cleanup func and does not require Cursor app.

## Depends-on

- p_0.10.1 settingSources
