# Phase p_0.10.2 — SystemPrompt and tool allow/deny

**Status:** done

## Goals

Match Cursor SDK local knobs: replace main system prompt; restrict built-in tools.

## Scope

- Public `Options.SystemPrompt` (replace Anvil default main prompt; tools/MCP still register)
- Built-in allow/deny lists (Cursor `tools` / `disallowedTools` idea): filter by public name or group (`shell`, `mcp`, `read`, …)
- Resolve naming vs existing custom `[]ToolSpec` (prefer distinct Go fields if needed)
- Not persisted across Resume unless passed again

## Non-goals

- Replacing MCP tool schemas via this API
- Per-subagent prompts (no sub-agents in 0.10)

## Tasks

1. Resolve naming clash with custom tool registration in design + Go API.
2. Implement filter at registry build time.
3. SystemPrompt override in Create/Resume/Prompt.
4. Unit tests.

## Acceptance

- [x] Denying `shell` omits shell from model tool list.
- [x] Non-empty `SystemPrompt` is what the loop sends as the system message (plus optional rules as documented).

## Depends-on

- Milestone 0.3 tools
