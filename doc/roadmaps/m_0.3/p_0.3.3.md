# Phase p_0.3.3 — Permission hooks

**Status:** done

## Goals

Optional approval callback before mutating tools.

## Scope

- `Options.Permission` hook invoked before `write_file`, `edit_file`, `shell`
- Decisions: allow / deny; optional args rewrite
- Deny returns a tool error to the model without crashing the run
- Default: allow all (nil hook)

## Non-goals

- Interactive TUI approval UI
- Network allowlists for shell

## Tasks

1. Define `PermissionRequest` / `PermissionDecision` public types.
2. Invoke hook from registry Execute for mutating tools.
3. Tests: deny blocks write.

## Acceptance

- [x] Deny hook blocks a write without crashing the run.
- [x] Nil hook preserves previous behavior.
