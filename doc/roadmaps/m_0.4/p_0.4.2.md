# Phase p_0.4.2 — Stronger edit tooling

**Status:** planned

## Goals

Improve multi-file / multi-hunk edits without abandoning cwd sandbox.

## Scope

- Add `apply_patch` (or equivalent) tool with clear failure modes
- Better `edit_file` errors (context hints when not unique)
- Optional read-before-write guidance in system prompt

## Non-goals

- AST-aware refactors / LSP rename
- Binary file editing

## Tasks

1. Spec patch format in this phase or a short design addendum.
2. Implement tool + tests.
3. Update system prompt tip sheet.

## Acceptance

- [ ] Patch tool can apply a multi-hunk change in tests.
- [ ] Failed edits return actionable errors to the model.
