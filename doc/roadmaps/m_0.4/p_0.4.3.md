# Phase p_0.4.3 — Project rules injection

**Status:** planned

## Goals

Load project instruction files into the agent system prompt when enabled.

## Scope

- Discover `AGENTS.md`, `.anvil/rules/*.md`, optional `.cursor/rules` opt-in (off by default)
- `LocalOptions.SettingSources` or `Rules: []string` / `LoadRules bool`
- Truncate oversized rules; never load secrets files (`.env`)

## Non-goals

- Executing rule scripts
- Team MDM sync

## Tasks

1. Spec discovery order in this phase.
2. Implement loader + prompt merge.
3. Tests with fixture repo tree.

## Acceptance

- [ ] With rules present and enabled, system prompt contains rule text.
- [ ] Default remains no ambient rule load (explicit opt-in).
