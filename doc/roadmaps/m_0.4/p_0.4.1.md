# Phase p_0.4.1 — Provider SSE streaming

**Status:** planned

## Goals

Stream assistant text deltas from OpenAI-compatible and Anthropic APIs.

## Scope

- Completer streaming API (or stream-capable Completer)
- Emit incremental `assistant` events with partial `Text`
- Tool-call assembly still correct when streamed
- oneshot/interactive optional `--stream` printing

## Non-goals

- Changing public Wait semantics
- Binary event protocols

## Tasks

1. Add SSE parsers for both providers.
2. Wire runtime emit deltas.
3. Tests with httptest chunked bodies.

## Acceptance

- [ ] Consumer sees multiple assistant deltas before done.
- [ ] Tool-calling runs still finish correctly.

## Depends-on

- Milestone 0.3 done
