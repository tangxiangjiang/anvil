# Milestone 0.4 — Coding UX

**Status:** done  
**Product version:** 0.4.x

## Goals

Raise local coding quality beyond the MVP tool loop: better edits, live streaming, and project-aware prompts.

## Overall acceptance

1. Callers can stream assistant text tokens (not only coarse events).
2. Multi-hunk or safer edits succeed more reliably than plain `edit_file` alone.
3. Repo rule files are loaded into the system prompt when enabled.

## Non-goals

- Full LSP / language server integration
- IDE plugin
- Cloud agents
