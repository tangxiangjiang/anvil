# Phase p_0.2.3 — Interactive multi-turn example

**Status:** planned

## Goals

Ship an example that demonstrates Resume + multi-turn local use.

## Scope

- `source/examples/interactive` CLI: create or resume by agent id, loop stdin prompts, print stream events, print agent id for resume
- README snippet for interactive usage
- Optional: honor Ctrl+C via Cancel once p_0.2.2 exists (can stub until then)

## Non-goals

- Full TUI / bubbletea UI
- Web UI

## Tasks

1. Implement interactive main.
2. Document env vars + resume flow.
3. Manual smoke checklist in this phase.

## Acceptance

- [ ] User can run two turns in one process with shared history.
- [ ] User can exit, `Resume` same id in a new process, continue.
- [ ] Example builds from `source/`.
