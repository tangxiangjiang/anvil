# Phase p_0.2.2 — Cancel and wall-time limits

**Status:** done

## Goals

Make runs interruptible and time-bounded.

## Scope

- Public `Run.Cancel(ctx)` cancels in-flight LLM HTTP and shell tool contexts
- `Options.MaxWallTime` (duration); exceeded → `RunResult.Status=cancelled` with message `max wall time exceeded`
- `MaxSteps` still applies independently (whichever hits first wins)
- Live runs always support Cancel (no supports() gate in 0.2)

## Non-goals

- Soft cancel that waits for current tool to finish cleanly beyond ctx cancel
- Cloud remote cancel APIs

## Tasks

1. Plumb cancel context from Run into Loop / Completer / shell.
2. Add MaxWallTime to Options; enforce with timer.
3. Tests: cancel mid-mock step; wall time exceeded.

## Acceptance

- [x] Cancel stops further LLM steps and marks run cancelled.
- [x] MaxWallTime exceeded ends the run without hanging.
- [x] Nil/zero MaxWallTime preserves prior behavior.
